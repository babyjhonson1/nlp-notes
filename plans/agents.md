## Содержание и границы

Первый раздел: ограничение одиночного вызова → выбор между workflow и агентным управлением → разделение участников → цикл и обновление состояния → остановка → минимальная реализация без фреймворка. Формализация связывает журнал, контекст, решение и наблюдение с кодом; обзор MDP/POMDP и RL не нужен.

Память, планирование, multi-agent, MCP, безопасность и оценка — будущие самостоятельные разделы; их порядок пока не согласован. Не расширять первый раздел каталогом технологий и не писать остальные без поручения.

## Особые договорённости

- Сквозной пример первого раздела — условная диагностика `ACCESS_CHECK_FAILED`: поиск инструкции, при необходимости статус `auth`, затем ответ либо запрос недоступных данных. Нормальный статус не доказывает ошибку прав; инцидент не доказывает причину конкретного обращения.
- Один шаг бюджета — решение модели, включая завершение. Предложение вызова, его исполнение и запись результата показываются раздельно.
- Python-цикл исполняемый; адаптер LLM не реализован, инструменты и решения учебного прогона условные. Иллюстрация демонстрирует заданные траектории без модели.
