# Регуляризация (ml/regularization) — 2026-10-15

## Источники

- Явное решение ridge, сжатие по SVD и \(\operatorname{df}(\lambda)\), MAP с гауссовым и лапласовым априорными, субградиентное условие лассо и \(\alpha_{\max}\), пороги при ортонормированных признаках, множители GD и ridge для ранней остановки — стандартные выводы, собственная запись; ESL гл. 3.4 и 7.10 (правило одной стандартной ошибки) — по памяти.
- Hoerl & Kennard (1970), Tibshirani (1996), Zou & Hastie (2005: групповой эффект, не больше n признаков у лассо при d > n), Friedman, Hastie & Tibshirani (2010), Meinshausen & Bühlmann (2010), Tikhonov (1963) — по памяти, формулировки общие.
- scikit-learn 1.9.1, руководство «Linear Models», просмотрено 2026-10-15: целевые функции `Ridge` (без 1/n), `Lasso` и `ElasticNet` (1/(2n), `l1_ratio`), `LogisticRegression` (средняя потеря плюс \(r(w)/(SC)\), свободный член штрафует только `liblinear`). Поведение `RidgeCV` без `cv` (эффективный LOO) и ошибка `StandardScaler` на разреженных данных без `with_mean=False` — по памяти о документации.

## Примеры и проверка

- Рисунок `reg-geometry`: потеря \((w-w^*)^\top A(w-w^*)\), \(w^*=(2,0.7)\), \(A=\)[[1, .5], [.5, 1]], штраф \(2.4\lVert w\rVert_1\) → решение \((1.15, 0)\); L2-решение с тем же бюджетом найдено бисекцией в JS.
- Рисунок `reg-path`: 60 условных отзывов, rng(1), оценка \(4-1.4\,\text{сломался}-0.6\,\text{брак}-0.6\,\text{бракованный}+0.7\,\text{отлично}+0.3\,\text{быстро}+\mathcal N(0,0.6^2)\); признаки стандартизованы; ridge — точное решение на 61 значении λ, лассо — покоординатный спуск с тёплым стартом на 81 значении α.
- `tools/test-regularization.py` (стандартная библиотека, около 3.5 с): исполняет блок кода из HTML и сверяет вывод; проверяет мягкий порог, решение и субградиентное условие на рисунке геометрии, качественное совпадение множителей ранней остановки; переносит генератор и пересчитывает корреляцию 0.94, \(\alpha_{\max}=0.69\), порядок входа слов (первым «бракованный», последним «курьер»), точки входа «брака» (≈0.54 \(\alpha_{\max}\)) и «курьера» (≈0.045 \(\alpha_{\max}\)), минимум пути «бракованного» −0.41 против OLS −0.35 и близость весов пары на пути ridge.
