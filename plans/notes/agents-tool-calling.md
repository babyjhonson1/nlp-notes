# Инструменты: исполнение и выбор из каталога

Дата: 2026-10-10. Раздел `agents/tool-calling`.

## Содержание и происхождение примеров

Основная линия переведена на выбор книги. Все магазины и данные условные, дата сценария 2026-10-08, срок доставки 2026-10-09. Два предложения совпадают с A/B первой тетради: «Лист» — 950 + 350 = 1300 рублей, «Полка» — 900 + 650 = 1550 рублей. Предложение C для разбора механики инструментов не нужно и в этом фрагменте отсутствует.

Практический граф реализует один ход: отбор набора по заданному этапу → ответ модели → исполнение пакета или завершение хода без вызовов. Переход этапов в демонстрации задан вручную. `ReplayModel` возвращает записанные решения, не оценивает сообщения и не является моделью. Поиск описаний по каталогу и восстановление после пропуска объяснены как устройство контроллера; они не выданы за реализацию показанного графа. Полный цикл остаётся заданием первой тетради.

Toolformer и разметка обеих иллюстраций сохранены дословно; они находятся в раскрывающихся дополнительных блоках. Формула маски допустимых токенов и таблица её гарантий сохранены по смыслу и согласованы с книжным примером. Текущий краткий мост к SFT не описывает закрытый рецепт конкретного чекпойнта.

[Прежняя техническая запись](../archive/agents-tool-calling-2026-10-09.md) содержит источники подробного разбора SFT/ToolLLM, данные токенизации Qwen, расчёты Toolformer и проверку старого адаптера. Проверки старого адаптера не относятся к новой реализации LangGraph. Числа в сохранившейся иллюстрации Qwen не пересчитывались; их происхождение и дата подписаны в тексте.

## Первоисточники

- [LangGraph Quickstart](https://docs.langchain.com/oss/python/langgraph/quickstart): состояние, узлы, условные переходы, сообщения и исполнение инструментов.
- [LangChain: Tools](https://docs.langchain.com/oss/python/langchain/tools), [Models / tool calling](https://docs.langchain.com/oss/python/langchain/models#tool-calling): описание из функции, `bind_tools`, `AIMessage.tool_calls`, связь `ToolMessage.tool_call_id`, независимые вызовы в пакете.
- Исходники установленного `langgraph.prebuilt.tool_node` версии 1.2.14: выбор по реестру, валидация, `ToolInvocationError` как наследник `ToolException`, `handle_tool_errors`, формирование сообщений. Поведение проверено исполняемым кодом ниже, а не только чтением документации.
- [Transformers: Tool use](https://huggingface.co/docs/transformers/en/chat_extras): описания/схемы попадают в шаблон, тело функции не передаётся, вызов и результат дописываются разными сторонами обмена.
- [MDN: API](https://developer.mozilla.org/en-US/docs/Glossary/API), [Fielding, глава 5](https://ics.uci.edu/~fielding/pubs/dissertation/rest_arch_style.htm): значение API и REST. Удалённый магазин не подключался.
- [ToolLLM v2](https://arxiv.org/html/2307.16789v2), §2.3 и §3.2: отдельный ретривер описаний API, передача выбранных операций решающей модели. Новых численных утверждений о качестве не добавлено. Обсуждение этапного отбора, бюджета и повторного поиска — устройство нашего приложения, не заявленный результат статьи.
- [MCP, Tools, редакция 2025-11-25](https://modelcontextprotocol.io/specification/2025-11-25/server/tools): `tools/list` для обнаружения описаний, `tools/call` для выполнения операции. MCP-сервер не запускался.
- [Toolformer](https://arxiv.org/html/2302.04761v1): сохранён прежний разбор, см. архивную запись для формул и параметров.
- [Grammar-Aligned Decoding](https://arxiv.org/abs/2405.21047) и [Efficient Guided Generation](https://arxiv.org/abs/2307.09702): сохранённая формализация маски и отличие локальной перенормировки от условного распределения на всей строке.

## Локальная проверка

Python 3.13.2; langgraph 1.2.14; langchain-core 1.6.9; pydantic 2.14.0. Использовано временное окружение первой практики, новые пакеты не устанавливались.

Три исполняемых Python-блока извлечены непосредственно из HTML, сущности декодированы, блоки объединены и выполнены. Вывод соответствует разделу: наборы `search_books` / `get_offer_details`, полные цены 1300 / 1550, срок 2026-10-09. Проверены сохранение истории между двумя запусками, два результата второго хода и их `tool_call_id`.

Проверены шесть ошибок: отсутствующий аргумент, неверный тип, лишнее поле, неизвестное предложение, неизвестное имя, зарегистрированный инструмент вне выбранного набора. Проверены отсутствие исполнения функции при ошибках схемы и возврат `ToolMessage(status="error")` с нужным ID. Ожидаемая предметная ошибка доходит до тела функции, а ошибка программы `KeyError` остаётся исключением. Отдельно проверены ветка текстового ответа и отказ для пустого ответа / `invalid_tool_calls`.

Сравнение с Git подтвердило дословную сохранность блока Toolformer и обоих элементов `figure`. Проверены существование локальных ссылок и якорей, `python3 tools/check.py`, `git diff --check`. Скрипт проверки использовался во временном каталоге; решение заданий тетради не публиковалось.

Модели, токенизаторы, обучение, серверы и бенчмарки не запускались; веса не скачивались, вызовов LLM через API не было. Выбор действий настоящей моделью и работа с живым магазином не проверены. Браузер не открывался: пользователь проверяет отображение раскрывающихся блоков, формул, иллюстраций и кода на узком экране.
