# Преобразование запросов и сборка контекста

2026-10-09. Раздел `rag/query-context`.

## Источники

- [Ma et al., 2023](https://aclanthology.org/2023.emnlp-main.322/): Rewrite–Retrieve–Read; обучение rewriter по обратной связи не требуется для нашего демонстрационного конвейера.
- [Gao et al., 2023](https://aclanthology.org/2023.acl-long.99/): HyDE; гипотетический документ используется как поисковое представление, а не источник фактов. В разделе показан вариант с одним документом.
- [Goldstein, Carbonell, 1998](https://aclanthology.org/X98-1025/), [PDF](https://aclanthology.org/X98-1025.pdf): MMR, релевантность минус максимальное сходство с выбранными.
- [Fu et al., 2021](https://aclanthology.org/2021.findings-emnlp.17/): пример декомпозиции RERC; общий приём в тексте не выдаётся за полную реализацию этого рецепта.
- [Liu et al., 2024](https://aclanthology.org/2024.tacl-1.9/): позиционные эффекты на исследованных моделях и задачах; универсального порядка источников из этого не следует.

## Условный пример

Корпоративное восстановление без почты продолжает материал `chunking/chunk-unit`. Версия v3 и срок в два рабочих дня после всех проверок придуманы для нового раздела, не измерены и не взяты из реального регламента.

Релевантности A/B/C/D: 0.90/0.88/0.75/0.30. Симметричные сходства AB/AC/AD/BC/BD/CD: 0.95/0.20/0.05/0.25/0.10/0.15. Это произвольные оценки в [0,1], не измеренные косинусы. Первый элемент выбирается по релевантности при любом весе, включая ноль; ничьи решаются порядком A/B/C/D.

- При λ=0.7: A → C → B. После A оценки B/C/D: 0.331/0.465/0.195.
- При λ=0.9: A → B → C.
- При λ=0.2: A → D → C.
- Граница выбора B вместо C после A: λ > 0.75/0.88.
- Бюджет: 1024 − 256 − 420 − 48 = 300. Условные стоимости A/B/C/D: 140/130/100/70. Упаковка первых трёх MMR-кандидатов при λ=0.7 оставляет A,C и занимает 240.

## Проверка и ограничения

Проверены структура сайта (`python3 tools/check.py`), синтаксис JavaScript, арифметика MMR в коде иллюстрации и исполнение именно опубликованного Python-примера, извлечённого из HTML. Проверены крайние веса, жадный выбор на сетке весов от 0 до 1, пересчёт максимального сходства, вложенность HTML и внутренние ссылки. Попарные оценки и длины не измерялись моделями или токенизатором. Веса не скачивались, модели и бенчмарки не запускались.

Браузерную проверку выполняет пользователь: шаги и изменение λ (сброс к началу), формулы в пояснениях, таблица на узком экране, светлая/тёмная тема. Это граница проверки, не поручение запускать модель.
