# XLM-R: происхождение чисел и проверки (2026-10-07)

## Источники

- Conneau et al., arXiv 1911.02116v2 (HTML-версия arXiv): MLM только на одноязычных данных, без языковых эмбеддингов; SentencePiece unigram, 250K; α = 0.3; CC-100 — 1 срез CommonCrawl для английского, 12 для остальных, fastText + внутренний классификатор, фильтр языковыми моделями по CCNet; «несколько сотен МиБ» как минимум для BERT; 1,5M шагов, батч 8192, 500 V100. Абляции (рис. 2–7, текст): XLM-7 → XLM-100 71.8 → 67.7; ширина 768/960/1152; словарь 32K → 256K +2.8 при равных параметрах, 128K → 512K > 3 на BERT-base; MLM без TLM 71.3 → > 75; выбор чекпойнта N моделей vs одна — 0.6 (на XLM). Таблица 1 (XNLI), 4 (GLUE, 6 задач: XLM-R 91.8, RoBERTa 92.8), 5 (одноязычные BERT vs XLM-7: ru 78.2 / 76.4 / 79.7), 6 (CC-100 по языкам), 7 (архитектуры и формула 4LH² + 2LH·H_ff + VH).
- Lample, Conneau, arXiv 1901.07291: формула q_i, n_i — число предложений; α = 0.5 для BPE, 0.7 для батчей; потоки по 256 токенов, батч из одного языка; TLM; языковые эмбеддинги.
- Wenzek et al. (CCNet), arXiv 1911.00359: нормализация абзацев и SHA-1, повторы — 70% текста; fastText 176 языков, порог 0.5; повторы до определения языка; KenLM 5-грамм на Википедии, трети head/middle/tail.
- Wu, Conneau et al., arXiv 1911.01464: перенос без общего словаря, решают общие параметры верхних слоёв; одноязычные BERT совмещаются ортогональным отображением.
- Goyal et al., arXiv 2105.00572: XL (36 × 2560, 3.5B), XXL (48 × 4096, 10.7B), pre-LN, батч 2048, 500K шагов, 0.5T токенов; large — 6T токенов, длина 512; CC-100 — 167B токенов, mC4 — 6.4T (в 38 раз больше). Таблица 1 (XNLI), 2 (GLUE, 5 задач: RoBERTa 92.9, L 91.9, XL 93.0, XXL 93.2). Текст статьи частично путает базу сравнения (+2.2/+2.4 «к XL»), в карточке — числа таблицы.
- Liang et al. (XLM-V), arXiv 2301.10472: кластеры языков и ALP; в среднем на 11.5% меньше токенов (FLoRes-200); +3.5 к переобученному авторами XLM-R по 7 задачам (таблица 2: 59.0 vs 55.5); шаг предобучения в 2.5 раза дольше. Доля словаря «93%» в статье не совпадает с подсчётом по конфигурации (89%), в карточке — подсчёт.
- Reimers, Gurevych, arXiv 2004.09813: «XLM-R mean» — STS 2017 одноязычные 42.7 (mBERT 54.0), межъязыковые 17.8; XLM-R-nli-stsb 55.6; дистилляция от SBERT-paraphrases 83.7; BUCC ru-en 22.1 → 88.6.
- XNLI, arXiv 1809.05053: 7500 новых английских пар, перевод профессиональными переводчиками. RoBERTa, arXiv 1907.11692: четыре изменения рецепта.

С головами предобучения сходится с метаданными safetensors: base 278 885 778, large 561 192 082, XL 3 482 741 760, mBERT 178 566 653 (с головой NSP). ## Токенизатор xlm-roberta-base

Скачаны только файлы токенизатора (tokenizer.json 9,1 МБ). transformers 4.57.6 и tokenizers 0.22.2: вывод блока «Что видит токенизатор» получен запуском. Нормализатор — Precompiled charsmap: м² → м2, № → No, … → ..., ﬁ → fi, полуширинная катакана → полная, NBSP → пробел; \n и \t → пробел; {, <, ~, ^, \, эмодзи сохраняются. Пара — `<s> A </s></s> B </s>`, token_type_ids не возвращаются. Пример MLM — токены предложения «Поисковая система получает короткий запрос и находит абзацы, которые на него отвечают.», маски выбраны вручную (условно).

Длина на условном параллельном абзаце (54 русских слова / 74 английских): XLM-R 87 / 92 токена, mBERT 102 / 92, bert-base-uncased 323 / 83.

Позиции: в transformers `create_position_ids_from_input_ids` начинает с padding_idx + 1 = 2, поэтому 514 эмбеддингов дают 512 токенов.

## Прежняя схема `xlmr-sampling` (до редакции 2026-10-09)

Объёмы — «Tokens (M)» таблицы 6 (сумма около 300 млрд, тогда как статья о XL называет 167 млрд — счёт токенов, видимо, разный). У украинского «6.5» при 84.6 ГиБ и шведского «77.8» при 12.1 ГиБ числа не сходятся с объёмом; взяты оценки 7123 и 2076 (по отношению токенов к ГиБ у русского и датского). Проходы = 6000 / 167 · q / p. Контрольные значения при α = 0.3: en 3.48% / 6.8, ru 2.68% / 12.5, sw 0.71% / 281, as 0.21% / 4650.

## Редакция 2026-10-09

Основная линия: пример одноязычного текста → MLM → распределение языков → новая NLI-голова → проверка переноса. Таблица режимов отделяет английское дообучение, обучающие переводы и перевод теста; переводы dev/test не названы предобучающими данными. NLI-пример про спокойное море заменён на ясное следование про два острова. Код показывает реальный optimizer.step, не выдаёт forward после одного backward за обученную модель.

В схеме теперь условные 100, 10 и 1 тысяча предложений. Вероятности точно считаются по формуле q ∝ n^alpha; справа q/p — относительная частота использования отдельного предложения при равном числе выборок. Это не реальные доли CC-100 и не число эпох. Прежняя реконструкция объёмов выше сохранена только как история происхождения старой схемы.

Уточнены границы выводов: словарь влияет на стоимость MLM-softmax, а не только на память; обучение по переводам — один способ получить хорошие межъязыковые эмбеддинги, не необходимое условие. Совместный классификатор пары не равен независимому эмбеддеру. Число слов в пределе 512 токенов не выводится из одного абзаца.

Повторно сверены [XLM-R](https://arxiv.org/html/1911.02116), [XL/XXL](https://arxiv.org/html/2105.00572), [XLM-V](https://arxiv.org/html/2301.10472); прочие исходные измерения и источники перечислены выше. Новых запусков моделей и токенизаторов не было. Проверки: tools/check.py, синтаксис JS, test-embedding-figures.cjs (включая арифметику и координаты графика на трёх ширинах). Браузер не открывался.
