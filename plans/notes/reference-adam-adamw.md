# Adam и AdamW — 2026-10-09

- [Adam](https://arxiv.org/abs/1412.6980), алгоритм 1: EMA первого и второго начального моментов, нулевая инициализация, поправки 1-beta^t. В тексте вывод поправки явно обусловлен постоянством математического ожидания; второй момент не назван дисперсией.
- [AdamW](https://arxiv.org/abs/1711.05101): отделение decay от статистик оптимизатора. Эквивалентность L2 и decay объяснена для SGD без инерции, не перенесена на произвольный оптимизатор.
- [PyTorch AdamW](https://docs.pytorch.org/docs/main/generated/torch.optim.AdamW.html) и [Adam](https://docs.pytorch.org/docs/main/generated/torch.optim.Adam.html), просмотрены 2026-10-09: конвенция (1-lr*weight_decay), epsilon вне корня, переключатель decoupled_weight_decay у Adam. Страницы main — изменяемая документация, не закреплённая версия установленной библиотеки.

Примеры условные, собственные арифметические расчёты. tools/test-adam.py исполняет первый блок кода прямо из HTML и проверяет таблицу двух шагов, пример L2 против AdamW и произведение коэффициентов decay. Только стандартная библиотека Python. PyTorch-фрагмент с моделью не запускался; веса не загружались. Иллюстрация не добавлялась: различие шагов наглядно в компактных таблицах. Всплывающие карточки не добавлялись.
