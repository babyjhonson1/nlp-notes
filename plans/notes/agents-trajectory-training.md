# Как модель учится пользоваться инструментами

Дата: 2026-10-12. Раздел `agents/trajectory-training`.

## Происхождение и границы

- Книжный пример — условный, согласован с `tool-calling`: сценарий 2026-10-08, срок 2026-10-09, предложения A/B, полные цены 1300/1550 рублей. Здесь оба инструмента доступны на каждом ходе, в отличие от этапного фильтра в предыдущем разделе. Журнал записан вручную, не получен от модели или магазина.
- Формула SFT задаёт выбранный учебный рецепт: цель только на ходах ассистента, включая окончание, среднее по целевым токенам; отдельно показана агрегация по батчу. Маска не объявляется рецептом Toolformer или закрытых моделей. Градиент по логитам — производная указанной cross-entropy, а не измеренный эффект дообучения.
- Код готовит три записи `tools + prompt + completion` со связями вызовов/результатов. Токенные ID в примере маски искусственные. Не выполнены сериализация настоящим шаблоном, токенизация или обучение; параметры TRL приведены по документации, без заявления о запуске trainer.
- Варианты наблюдений, требования к данным и награда для книжного примера — учебные конструкции. Они не являются строками ToolBench или результатами эксперимента.

## Перенос иллюстраций

Toolformer, таблица кандидатов и обе интерактивные иллюстрации перенесены из `tool-calling`. Код/стили получили префикс `att`, подключения в `index.html` обновлены; общая верстка и дизайн сохранены. В старом разделе сохранён якорь `tc-train` и добавлены ссылки на новый раздел; его практический код не менялся.

Сохранены шесть шагов Toolformer, взвешенные потери и разности 1,56 / 0,12 / 0,08. Уточнения по статье:

- порог позиций — строгое `p_i > tau_s`;
- эксперимент исключает тексты, у которых все кандидаты отброшены (§4.1); этот исход исправлен в иллюстрации и тексте;
- более высокий порог требует большего снижения потери, но не гарантирует истинности результата; обучение обычному тексту не названо гарантией сохранения качества.

В иллюстрации Qwen сохранены прежние тексты и числа: 792 токена обучения, 88 целевых, 352 токена описаний; генерация — 791/85. Это результат подсчёта токенизатором от 2026-10-08, он здесь не повторялся. Прежнее происхождение — [запись по инструментам](agents-tool-calling.md) и её [снимок](../archive/agents-tool-calling-2026-10-09.md). Формат конкретного чекпойнта не обобщён на все модели Qwen. Пояснение маски уточнено: исключена прямая потеря, токены остаются во входе.

## Первоисточники

- [Toolformer, v1](https://arxiv.org/html/2302.04761v1), §2, §4.1–4.2 и приложение A: генерация кандидатов, исполнение, фильтр, объединение, обычное языковое моделирование; пять инструментов и ограничение одного вызова при оценке. Числа таблицы поиска по Википедии сохранены из статьи; потери A/B/C условные.
- [ToolLLM, v2](https://arxiv.org/html/2307.16789v2), §2–3.2: задания по сочетаниям API, разметка путей учителем, отбор и дообучение LLaMA-2. Рейтинг моделей и численные выигрыши не пересказывались.
- [Search-R1](https://arxiv.org/abs/2503.09516): подтверждён пример многошагового поиска в RL с сигналом итогового ответа. Без обзора алгоритмов RL и без переноса результатов статьи на книжный сценарий.
- [TRL: формат tool calling](https://huggingface.co/docs/trl/dataset_formats#tool-calling), [SFTTrainer](https://huggingface.co/docs/trl/sft_trainer): сообщения, поле `tools`, `function.arguments`, prompt/completion, assistant-only и completion-only маски, сдвиг меток. Документация прочитана 2026-10-12; локально TRL не запускался. Для будущего обучения нужно зафиксировать версии и проверить конкретный шаблон.

## Проверка

- Три Python-блока извлечены непосредственно из HTML и исполнены стандартной библиотекой. Получены длины префиксов 2/4/7, вызовы поиска, пакет двух проверок и ответ. Проверены точные срезы исходного журнала, отсутствие будущих наблюдений, связи `tool_call_id`, JSON и независимость копий.
- Маска проверена для префикса, ответа, окончания и padding; ошибки длины, небинарной маски и отсутствия целей вызывают исключение. Производная cross-entropy проверена конечными разностями на условных логитах, в том числе при нулевой маске. Модель в этой проверке отсутствует.
- В jsdom проверены обе перенесённые иллюстрации: шесть шагов, кандидаты, разности потерь, переход порога 1,55 → 1,60, исключение текста без кандидатов, переключение генерации/обучения, счётчики, порядок управления и очистка обработчиков. Использован уже установленный jsdom, без сетевых ресурсов и браузера.
- Практический блок предыдущего раздела сравнен с Git: дословно сохранён. Проверены внутренние ссылки и якоря, синтаксис JavaScript, `python3 tools/check.py`, `git diff --check`.

Модели, обучение, бенчмарки, токенизаторы и серверы не запускались, веса не скачивались. Отображение формул, таблиц и иллюстраций на узком экране проверяет пользователь в браузере.
