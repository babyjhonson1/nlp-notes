# Реализации градиентного бустинга. Источники и проверка

Сверка 2026-11-06. Раздел `ml/boosting-libraries`.

- Chen, Guestrin, 2016, §2.1–2.3 и §3.4. Квадратичное приближение, штраф за вес и число листьев, оценка разбиения и перебор направлений для пропусков. Ползунки считают gain по формуле (7) в нормировке статьи. Назначение `min_child_weight` сверено по документации ветки 3.2. [Статья](https://arxiv.org/abs/1603.02754), [параметры](https://xgboost.readthedocs.io/en/release_3.2.0/parameter.html).
- Ke et al., 2017, §3–4. GOSS и EFB. Гистограммы, вычитание гистограмм, рост по листьям, категориальные разбиения, режим GOSS и API ранней остановки сверены с документацией LightGBM 4.6.0. [Статья](https://papers.nips.cc/paper_files/paper/2017/hash/6449f44a102fde848669bdd9eb6b76fa-Abstract.html), [механизмы](https://lightgbm.readthedocs.io/en/v4.6.0/Features.html), [API](https://lightgbm.readthedocs.io/en/v4.6.0/pythonapi/lightgbm.LGBMClassifier.html).
- Prokhorenkova et al., 2018, §3–5. Упорядоченные статистики и вспомогательные предсказания для градиентов. Статистика в проигрывателе использует учебные параметры сглаживания. Подпись `fit` сверена по тегу CatBoost 1.2.8, политика симметричных деревьев и режимы бустинга — по документации. [Статья](https://arxiv.org/abs/1706.09516), [код версии](https://github.com/catboost/catboost/blob/v1.2.8/catboost/python-package/catboost/core.py), [параметры](https://catboost.ai/docs/en/references/training-parameters/common).
- Grinsztajn, Oyallon, Varoquaux, 2022. Сравнение классических деревьев и изученных нейросетей на 45 табличных задачах. Число строк порядка 10 тысяч относится к режиму этого сравнения. [Статья](https://arxiv.org/abs/2207.08815).

Числовые примеры условные. Метки заказов совпадают с `gb-steps`. Для гистограммы задержки заданы целыми числами от одного до восьми. В кодировании продавца используется один выбранный порядок из четырёх заказов. `python3 tools/test-boosting-libraries.py` проверяет обе ветки для пропусков, гистограмму, веса и gain, коды продавцов и синтаксис Python-примера.
