## Деревья и ансамбли — основной вес

### Дерево решений (`trees`)

| Вопрос | Что должно быть в ответе |
| --- | --- |
| Как строится дерево? | Жадно, сверху вниз; перебор признаков и порогов между соседними отсортированными значениями; стоимость узла \(O(d\,n\log n)\) с сортировкой или \(O(d\,n)\) с гистограммами |
| Gini, энтропия, MSE: формулы и смысл | Gini — вероятность ошибки при случайной разметке по долям узла; энтропия; прирост как взвешенное уменьшение неопределённости; MSE → дисперсия в узле. Почему не accuracy (misclassification) как критерий: кусочно-линейна, часто не видит улучшения разбиения |
| Что предсказывает лист | Среднее для MSE, медиана для MAE, доли классов для классификации |
| Как бороться с переобучением дерева | max_depth, min_samples_leaf, min_impurity_decrease; cost-complexity pruning с \(\alpha\) |
| Почему дерево неустойчиво | Жадный выбор первого разбиения меняется от малых изменений данных → высокая дисперсия |
| Нужна ли нормализация признаков | Нет: разбиения инвариантны к монотонным преобразованиям признака |
| Экстраполирует ли дерево (лес, бустинг на деревьях) | Нет: кусочно-постоянная функция, вне диапазона обучения — константа; пример с трендом по времени |
| Как обрабатываются категориальные признаки | One-hot против порядкового кода; для бинарной цели и MSE — оптимальное разбиение сортировкой категорий по средней цели (CART); риск при высокой кардинальности |
| Как обрабатываются пропуски | Суррогатные разбиения (CART), направление по умолчанию (XGBoost, LightGBM), поддержка NaN в деревьях scikit-learn — версию сверить |
| Что дерево плохо приближает | \(y=x_1+x_2\) — лестница; XOR — жадный критерий не видит пользы первого разбиения |
| Важность признаков | MDI смещена к признакам с многими значениями и считается на train; permutation importance и проблема коррелированных признаков; SHAP — кратко |

### Бэггинг и случайный лес (`trees`)

| Вопрос | Что должно быть в ответе |
| --- | --- |
| Что такое бэггинг и почему он работает | Бутстрэп; дисперсия среднего \(\rho s^2+\frac{1-\rho}{B}s^2\); смещение почти не меняется |
| Какая доля объектов попадает в бутстрэп-выборку | \(1-(1-1/n)^n\to1-1/e\approx0.632\); остальные — OOB |
| OOB-оценка | Прогноз по деревьям, не видевшим объект; замена кросс-валидации |
| Зачем случайные подмножества признаков | Декорреляция деревьев (уменьшение \(\rho\)); типичные значения max_features — с источником и версией библиотеки |
| Переобучается ли лес с ростом числа деревьев | По числу деревьев ошибка выходит на плато; переобучение возможно из-за глубины и шума, а не из-за \(B\) |
| Почему лес из глубоких деревьев, а бустинг из неглубоких | См. `generalization`, раздел bias–variance; в разделе о лесе — подробнее |
| Лес и бустинг: параллелизм | Деревья леса независимы; бустинг последователен по деревьям, параллелен внутри дерева |
| Extra Trees | Случайные пороги: ещё меньше корреляция, больше смещение |

### Градиентный бустинг (`boosting`)

| Вопрос | Что должно быть в ответе |
| --- | --- |
| Общая схема | Аддитивная модель \(F_m=F_{m-1}+\nu h_m\); функциональный градиентный спуск; дерево \(h_m\) — регрессионное, приближает антиградиент (псевдоостатки) по MSE; значения листьев затем оптимизируются под исходную потерю |
| **Бинарная классификация: что предсказываем, какая потеря, какой таргет у деревьев** | Модель предсказывает логит \(F(x)\), \(p=\sigma(F)\); потеря — log-loss; \(F_0=\log\frac{\bar y}{1-\bar y}\); псевдоостаток \(r_i=y_i-p_i\); деревья регрессионные, учатся на \(r_i\) по MSE; значение листа — шаг Ньютона \(\frac{\sum(y_i-p_i)}{\sum p_i(1-p_i)}\); шаг \(\nu\); на выходе \(\sigma(F_M)\). Числовой пример на нескольких объектах |
| Многоклассовая классификация | \(K\) деревьев на итерацию, softmax, \(r_{ik}=y_{ik}-p_{ik}\); формула листа Friedman (2001) сверить |
| Регрессия с разными потерями | MSE → остатки, лист = среднее; MAE → знак остатка, лист = медиана; Huber; quantile loss → квантиль |
| Learning rate и число деревьев | Компромисс; ранняя остановка по validation; subsample и colsample (stochastic GB) |
| Переобучается ли бустинг с ростом числа деревьев | Да, в отличие от леса; поэтому ранняя остановка |
| Градиентный бустинг и AdaBoost | AdaBoost — forward stagewise с экспоненциальной потерей (Friedman, Hastie, Tibshirani, 2000); чувствительность к шуму в метках |
| XGBoost: откуда формулы | Тейлор второго порядка; \(w^*=-G/(H+\lambda)\); прирост разбиения со штрафом \(\gamma\); для log-loss \(g=p-y\), \(h=p(1-p)\); смысл min_child_weight как суммы гессианов |
| LightGBM | Гистограммы; рост по листьям (num_leaves) против роста по уровням; GOSS и EFB — что дают |
| CatBoost | Утечка цели при наивном target encoding → ordered target statistics; prediction shift и ordered boosting; симметричные (oblivious) деревья и быстрый инференс |
| Какие гиперпараметры подбирать и в каком порядке | Learning rate + ранняя остановка → сложность деревьев → сэмплирование → регуляризация; рекомендация, не правило |
| Бустинг, лес или нейросеть на таблицах | Эмпирические сравнения (например, Grinsztajn et al., 2022) с их условиями |
| Важность признаков в бустинге | gain, split count, SHAP; расхождения между ними |

## Остальные разделы главы

| Раздел | Вопросы |
| --- | --- |
| `generalization` (готов) | Переобучение и недообучение, диагностика; почему ошибка на train занижена; вывод bias–variance и условия; нет аналога для 0–1; как ручки (k, глубина, \(\lambda\), бэггинг, бустинг) двигают смещение и дисперсию; поможет ли больше данных; проклятие размерности, масштабирование и сложность kNN; double descent |
| `validation` | Train/validation/test и смещение оценки лучшей конфигурации; nested CV; k-fold, стратифицированное, групповое, временное разбиение; примеры утечек (предобработка на всех данных, дубликаты, признаки из будущего, target encoding); grid, random и байесовский поиск; статистическое сравнение двух моделей |
| `linear-models` | MSE как MLE и предпосылки линейной регрессии; нормальное уравнение, стоимость, мультиколлинеарность; почему не MSE с сигмоидой для классификации; вывод log-loss и градиент \((p-y)x\); интерпретация весов; разделимые данные; softmax против one-vs-rest |
| `regularization` | Почему L1 даёт разреженность; байесовская интерпретация; elastic net; масштаб признаков; свободный член не штрафуется; `C` в scikit-learn |
| `optimization` | GD, SGD, mini-batch; обусловленность и нормировка; momentum; Ньютон и IRLS; когда L-BFGS |
| `naive-bayes` | Почему «наивный»; сглаживание Лапласа; NB как линейный классификатор; генеративные и дискриминативные модели; переуверенные вероятности |
| `svm` | Зазор и hinge loss; роль \(C\); опорные векторы; kernel trick и \(\gamma\) у RBF; SVM против логистической регрессии; почему нет вероятностей |
| `reference/classification-metrics` | Precision, recall, \(F_\beta\); ROC-AUC как вероятность правильно упорядочить пару, Gini \(=2\,\text{AUC}-1\) (скоринг); ROC-AUC против PR-AUC при дисбалансе; macro и micro; log-loss |
| `calibration` | Выбор порога по стоимости ошибок; почему accuracy вводит в заблуждение; веса классов, ресэмплинг, SMOTE и их влияние на вероятности; Platt и изотоническая калибровка; калиброваны ли логрегрессия, NB, лес, бустинг |
| `learning-to-rank` | Pointwise, pairwise, listwise; RankNet → LambdaRank → LambdaMART; nDCG; группы запросов в LightGBM |
| `clustering` | Алгоритм k-means, сходимость, k-means++; выбор k (локоть, силуэт) и их ограничения; DBSCAN и его параметры; GMM и EM; k-means как предельный случай |
| `dim-reduction` | PCA через SVD, нужна ли стандартизация, доля объяснённой дисперсии; LSA без центрирования; почему t-SNE и UMAP — только визуализация |

## Темы вне текущего плана

Часто спрашивают, но места в плане нет; решение — за пользователем: стекинг и блендинг с out-of-fold прогнозами; кодирование категориальных признаков и target encoding вне CatBoost; Isolation Forest. В границах существующих разделов, но в плане явно не названы: MAE, Huber и quantile loss (бустинг), SMOTE (калибровка и дисбаланс), Gini \(=2\,\text{AUC}-1\) (метрики классификации).
