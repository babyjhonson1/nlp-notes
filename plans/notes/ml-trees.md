# Деревья решений (ml/trees) — 2026-10-28

## Источники

- ESL, гл. 9.2 (по памяти о тексте): два прочтения Gini (ошибка случайного правила и сумма дисперсий индикаторов), пример с долей ошибок и предпочтение Gini/энтропии при росте, неустойчивость деревьев (9.2.4), оптимальное разбиение категорий сортировкой по доле класса и для регрессии по среднему (доказательства — Breiman et al., 1984, и Fisher, 1958), переобучение на категориях с многими уровнями.
- Breiman et al. (1984), Quinlan (1986, 1993), Hyafil & Rivest (1976: NP-полнота для минимальной средней длины пути) — по памяти, формулировки общие. Утверждение Raileanu & Stoffel (2004) о доле случаев, когда Gini и энтропия расходятся, проверить не удалось (страница статьи недоступна): в тексте оставлено только как общее эмпирическое наблюдение без числа и без ссылки.
- Strobl et al. (2007, BMC Bioinformatics 8:25): смещение импурити-важности к признакам с большим числом точек разбиения — подтверждено поиском 2026-10-28.
- scikit-learn 1.9.1, просмотрено 2026-10-28: `DecisionTreeClassifier` (сигнатура, `criterion` gini/entropy/log_loss, `predict_proba` — доля класса в листе, `ccp_alpha`, `monotonic_cst` с 1.4 и его ограничения, случайная перестановка признаков при `splitter="best"` — по памяти о документации); руководство по деревьям: формулы критериев, лист MAE — медиана, обработка `NaN` при обучении и предсказании (в том числе «в ребёнка с большим числом объектов», если пропусков не было), отсутствие нативных категориальных признаков, формулы обрезки по сложности, оценки сложности.

## Примеры и проверка

- Все данные условные. Пример 7 из 10 → (4 из 4) и (3 из 6); категории книги 4/40, одежда 10/50, бытовая техника 12/30, электроника 20/40.
- Рисунок `tree-grow`: rng(3), 50 заказов для обучения и rng(1003), 1000 для validation; задержка — 0–10 дней с шагом 0.1, цена — 0–40 тыс. ₽ с шагом 0.1; вероятность негатива 0.85 при задержке > 6, 0.8 при задержке > 3 и цене > 25, иначе 0.1. Рост «лучший лист первым» по взвешенному уменьшению Gini. Seed выбран среди нескольких по наглядности истории (корень по задержке, затем цена, затем порог 3 дня).
- Рисунок `tree-extrap`: rng(21), 24 месяца, \(y=30+2.5t+4\varepsilon\), одномерное дерево глубины 3 по минимуму суммы квадратов.
- `tools/test-trees.py` (стандартная библиотека, < 1 с): исполняет блок кода из HTML и сверяет вывод; перебирает все 7 разбиений категорий (оптимум 0.0448, one-hot и алфавитный код — 0.0301); проверяет формулы прироста Gini и суммы квадратов на 200 случайных разбиениях; пересчитывает пример с тремя критериями и приросты на рисунке хорды; переносит генератор `rng` и рост дерева из `figures/tree.js` (с округлением как `Math.round`) и проверяет корень (задержка 6.05, прирост 0.290, по цене 18.8 и 0.051), неизменность ошибок после второго разбиения, 8 % и 15 % после трёх, минимум validation на третьем шаге, 13 разбиений и 0 % / 20 % у полного дерева, байесовскую ошибку около 13 %; для рисунка экстраполяции — 8 листьев и константу после 24-го месяца.
- Пошаговый рисунок прогнан в node на заглушке DOM (переключение кадров, тексты пояснений); все три рисунка отрисованы в PNG через rsvg-convert. В браузере не открывались. Код scikit-learn не запускался.
