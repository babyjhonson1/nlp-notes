# Практика 1: источники и границы проверки

Дата: 2026-10-10. Файлы — `practice/agents/01_workflow_and_agent.ipynb`, `lab01_support.py`, `lab01_checks.py`.

## Контракт и данные

- Две архитектуры: фиксированный workflow и цикл с решениями модели. Студент заполняет четыре функции и добавляет свой сценарий. В служебных файлах нет контрольного решения графов.
- Книга и предложения совпадают с эпизодом `agents/context-memory`: A — 950 + 350 = 1300 руб., B — 900 + 650 = 1550 руб., C — 800 + 200 = 1000 руб., но английский язык. Срок 2026-10-09; даты сценария не зависят от дня запуска. Все данные условные.
- `search_books` скрывает доставку; `get_offer_details` возвращает полные условия. Только чтение локальных данных, без покупок. Состояние workflow и агента различается намеренно.
- `ScriptedModel` выдаёт заранее записанные сообщения, `LoopingModel` проверяет предел решений. Одна итерация — решение модели; в основном сценарии три решения и четыре исполнения инструментов. Пакет из трёх независимых проверок исполняется последовательно. На пределе решения вызванные инструменты ещё исполняются, результаты записываются, затем граф завершает работу без нового вызова LLM.
- У начального сообщения задан стабильный id. Это устраняет побочное назначение id редьюсером `add_messages` во входном объекте и позволяет проверять неизменность начального состояния.

## Первоисточники

- [LangGraph Quickstart](https://docs.langchain.com/oss/python/langgraph/quickstart) и [Graph API](https://docs.langchain.com/oss/python/langgraph/graph-api): состояние, функции узлов, переходы, compile/invoke/stream и редьюсеры сообщений. Граф учебный, не копия готового агента.
- [LangGraph Test](https://docs.langchain.com/oss/python/langgraph/test): проверка узлов и графа. Здесь применены обычные проверки контрактов на фиксированных данных.
- [HF Inference Providers](https://huggingface.co/docs/inference-providers/index), [Function Calling](https://huggingface.co/docs/inference-providers/guides/function-calling), [InferenceClient](https://huggingface.co/docs/huggingface_hub/package_reference/inference_client): токен с правом Inference Providers, `chat_completion`, tools, tool_choice, сообщения результатов. Адаптер использует `huggingface_hub`, модель и провайдер пока не выбраны.
- [HF Pricing](https://huggingface.co/docs/inference-providers/pricing), проверено 2026-10-10: бесплатный аккаунт не получает включённые кредиты; для вызовов нужна покупка кредитов. Доступ к конкретному аккаунту или модели не проверялся.
- [Langfuse: LangChain/LangGraph](https://langfuse.com/integrations/frameworks/langchain): CallbackHandler и передача трасс. Интеграция запланирована в третьем практикуме и разделе оценки; SDK Langfuse сейчас не устанавливался, трассы не отправлялись.

## Проверка

Во временное окружение установлены только библиотеки. Python 3.13.2, LangGraph 1.2.14, langchain-core 1.6.9, huggingface-hub 1.33.0, nbformat 5.11.1, ipykernel 7.4.0; основные зависимости закреплены в requirements.txt.

- nbformat.validate и синтаксис всех Python-ячеек; отсутствие outputs и execution_count в выдаваемой тетради.
- Все кодовые ячейки исполнены по порядку с временной контрольной реализацией четырёх функций. Реальные графы LangGraph прошли проверки фильтра, двух ветвей workflow, пустого поиска, исполнителя, соответствия id, ошибок имени/аргументов/исполнения, полного журнала, финального ответа, исправления вызова и предела решений. Собственный сценарий и текстовые ответы остаются заданиями читателя.
- HF-адаптер проверен подставным клиентом: сообщения и схемы запроса, разбор вызова, usage, обработка обрыва по длине. Настоящий запрос к HF не делался.
- `python3 tools/check.py` и `git diff --check`. Визуальная проверка в интерфейсе Jupyter не проводилась; браузер не открывался.

Контрольное решение находится только во временной папке и не включено в репозиторий. Модели, обучение и бенчмарки не запускались, веса не скачивались. Пользователь ещё не решал тетрадь; зелёные авторские проверки не означают выполнение работы пользователем или качество настоящей LLM.
