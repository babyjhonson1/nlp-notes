# Линейная и логистическая регрессия (ml/linear-models) — 2026-10-14

## Источники

- MSE как MLE, нормальное уравнение, \(\operatorname{cond}(X^\top X)=\operatorname{cond}(X)^2\), VIF для двух признаков, градиент и гессиан log-loss, \(\sum_i(p_i-y_i)=0\) при свободном члене, MLE для одного бинарного признака через логарифмы шансов групп — стандартные выводы, собственная запись; ESL гл. 3 и 4.4 — учебная ссылка по памяти.
- Теорема Гаусса — Маркова, Cox (1958), Nelder & Wedderburn (1972), Albert & Anderson (1984) — по памяти, формулировки общие.
- Soudry et al., JMLR 2018 (arXiv 1710.10345): рост нормы как логарифм числа шагов и сходимость направления к максимальному зазору — по памяти о статье.
- scikit-learn 1.9.1, просмотрено 2026-10-14: `LogisticRegression` (`penalty` устарел в 1.8, удаление в 1.10, вместо него `l1_ratio` и `C`; `C=np.inf` — без штрафа; решатель по умолчанию `lbfgs`, `max_iter=100`; при 3+ классах все решатели, кроме `liblinear`, оптимизируют мультиномиальную потерю), `LinearRegression` (`scipy.linalg.lstsq` для плотных данных).
