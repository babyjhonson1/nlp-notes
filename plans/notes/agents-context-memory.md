# Контекст и память: источники, данные и проверка

Дата: 2026-10-08. Раздел `agents/context-memory`, префикс `acm`.

## Первоисточники

- Liu et al., [Lost in the Middle](https://aclanthology.org/2024.tacl-1.9/), TACL 2024: многодокументные вопросы и поиск ключей, зависимость качества исследованных моделей от положения информации. В конспекте нет новых замеров и переноса результата на любую современную модель.
- Packer et al., [MemGPT](https://arxiv.org/html/2310.08560v2), раздел 2, редакция 2024 (препринт 2023): данные за пределами основного контекста нужно возвращать в него через операции памяти. Собственный сборщик не объявляется реализацией MemGPT.
- Wu et al., [LongMemEval](https://arxiv.org/abs/2410.10813), ICLR 2025: временные отношения и обновление знаний как отдельные способности. Бенчмарк не запускался; численные результаты из статьи не воспроизводятся.
- Anthropic, [Effective context engineering for AI agents](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents), 2025-09-29: compaction, заметки вне окна и риск потери существенных деталей.
- Hugging Face, [Chat templates](https://huggingface.co/docs/transformers/main/en/chat_templating) и [apply_chat_template](https://huggingface.co/docs/transformers/main/en/internal/tokenization_utils), проверено 2026-10-08: шаблон чата и служебные токены, параметры tools, tokenize, add_generation_prompt, return_dict и truncation. В актуальной API-документации return_dict по умолчанию True; пример явно ставит False, чтобы len считал идентификаторы токенов. Версия пакета локально не устанавливалась; адаптер сверён с документацией, а не исполнен.

## Данные нового сквозного примера

Все магазины и предложения вымышлены. Просьба 2026-10-08: бумажный «Маленький принц» на русском, максимум 1500 руб. вместе с доставкой, получить не позднее пятницы 2026-10-09. Оформление требует отдельного подтверждения.

| ID записи | Содержание |
| --- | --- |
| e1 | Исходная просьба со всеми условиями. |
| e2 | A, «Лист»: русский, бумага, книга 950 + доставка 350 = 1300 руб.; дата получения 2026-10-09; прочитано 2026-10-08 10:00. |
| e3 | B, «Полка»: русский, бумага, 900 + 650 = 1550 руб.; получение 2026-10-09; исключается по полной стоимости. |
| e4 | C, «Том»: английский, бумага, 800 + 200 = 1000 руб.; получение 2026-10-08; исключается по языку. |
| e5 | Последний вопрос «Какой вариант подходит?». |

В блоке о продолжении 2026-10-09 пользователь явно меняет бюджет на 1400 руб. Новое чтение A даёт 1100 + 350 = 1450 руб. и меняет допустимость предложения; прежняя цена сохранена только как прошлое наблюдение. Это развитие того же примера после эпизода иллюстрации, не одновременные противоречащие цены.

## Условная арифметика иллюстрации

Все размеры выбраны для демонстрации и не являются длинами токенизации показанных текстов. В арифметике оформление блоков включено в их размеры, фиксированная часть — 512, резерв генерации — 512. Окно 4096 оставляет 3072 токена переменных данных.

- Журнал: e1 = 256; e2/e3/e4 = 1024 каждый (каждая группа включает вызов и результат); e5 = 128. Всего 3456, превышение бюджета данных 384.
- Непрерывный хвост по умолчанию: e3/e4/e5 = 2176. Добавить e2 нельзя: получится 3200. При окне 4352 весь хвост предложений помещается, но e1 ещё нет. Вся история помещается при окне 4480.
- Неудачная сводка e1–e3 = 320; e4/e5 = 1152; вместе 1472. Потеряна доставка и её включение в бюджет; увеличение окна не исправляет сводку.
- Состояние e1–e3 = 640; вместе с e4/e5 = 1792. Помещается ровно при окне 2816, не помещается при 2560. Состояние и последние наблюдения в этих двух режимах обязательны; скрытого усечения нет.
- Счётчики проверяют вместимость, а тексты исходов — достаточность сохранённых данных в этом конкретном примере. Это не измерение качества LLM и не прогноз её ответа.

## Проверка и ограничения

- Основной Python-блок извлечён из HTML и исполнен на системном Python 3.13.2 с тестовым счётчиком. Проверены обязательное переполнение, точная граница бюджета, исключение слишком большой записи с последующим включением маленькой, пустая память, недопустимые лимиты и результаты счётчика, сохранение целых последних сообщений и отсутствие мутаций исходных объектов. Счётчик тестирует ветвления; он не токенизатор.
- Блок адаптера Transformers скомпилирован как Python и сверён с указанной API-документацией; не исполнен. Токенизаторы и веса не скачивались, модели и бенчмарки не запускались. Длина реального модельного входа не измерялась.
- Node: 52 комбинации четырёх способов сборки и 13 размеров окна; отдельно точные пороги 2816/4480, потеря e1 при 4352, недостаточность сводки даже в большом окне. На лёгкой подстановке DOM проверены переключение режима, ползунок, сброс, aria-pressed и очистка обработчиков. Синтаксис всех assets/*.js и figures/*.js проверен.
- `python3 tools/check.py` проходит. Браузер не открывался; расположение карточек, формулы после переключений и тёмную тему проверяет пользователь.
- Связанные утверждения в `agent-loop` и `tool-calling` согласуются с разделением состояния/контекста и учётом описаний инструментов. В `inference/paged-attention` расчёт повторного использования дан для дописываемой истории; новый раздел явно оговаривает изменение префикса при пересборке. Соседние разделы не менялись.
