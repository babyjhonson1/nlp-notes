# Градиентный бустинг. Источники и проверка

Сверка 2026-11-06. Раздел `ml/boosting`.

- Friedman, 2001, §3–5 и алгоритмы 2–6. Общий шаг по псевдоостаткам, выбор разбиений, пересчёт значений листьев, регуляризация. Бинарный алгоритм в статье использует метки \(\{-1,+1\}\) и половину логита. В тексте используются \(\{0,1\}\) и полный логит, поэтому поправка имеет вид \(\sum(y-p)/\sum p(1-p)\). Для многоклассового алгоритма 6 сохранён множитель \((K-1)/K\). При one-hot метках \(|y_k-p_k|(1-|y_k-p_k|)=p_k(1-p_k)\). [Статья](https://doi.org/10.1214/aos/1013203451).
- Friedman, 2002, §1–2. Подвыборка строк без возвращения на каждом шаге. Ограничение признаков зависит от реализации. [Статья](https://doi.org/10.1016/S0167-9473(01)00065-2).
- Friedman, Hastie, Tibshirani, 2000, §2–4. Поэтапная оптимизация экспоненциальной потери в дискретном бинарном AdaBoost. [Статья](https://doi.org/10.1214/aos/1016218223).
- scikit-learn 1.9.1. Сверены имена потерь, параметры внутренней валидации, атрибут числа итераций и промежуточные прогнозы. Пример проверен на синтаксис. Обучение и загрузка данных не выполнялись. [Классификатор](https://scikit-learn.org/1.9/modules/generated/sklearn.ensemble.GradientBoostingClassifier.html), [регрессор](https://scikit-learn.org/1.9/modules/generated/sklearn.ensemble.GradientBoostingRegressor.html).

Числа в разделе условные. В примере со звёздами вручную посчитаны остатки и MSE при полной поправке. В примере с восемью заказами оба признака двоичные, возможны ровно два разбиения дерева с одним вопросом. Скрипт `tools/test-boosting.py` сравнивает ошибки приближения псевдоостатков для обоих разбиений на каждом шаге, проверяет поправки листьев, вероятности и среднюю log-loss. Проигрыватель в `figures/gb.js` вычисляет те же скалярные поправки для разбиений из текста.
