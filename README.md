# Конспекты по NLP

Личные конспекты по NLP в виде сайта: главы и разделы, формулы в LaTeX, интерактивные иллюстрации.

- Правила для редакторов и агентов: [AGENTS.md](AGENTS.md)
- Посмотреть локально: `python3 -m http.server 8000` в корне репозитория, затем http://localhost:8000
- Проверить перед коммитом: `python3 tools/check.py`

Сайт публикуется на GitHub Pages автоматически после каждого коммита в `main`, если проверка прошла.
