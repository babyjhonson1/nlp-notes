В случайном лесе деревья строятся независимо и усредняют свои прогнозы. В градиентном бустинге (gradient boosting) каждое новое дерево оценивает поправку к прогнозу уже обученного ансамбля. Для квадратичной потери дерево учится предсказывать обычный остаток. Для вероятности негативного отзыва дерево подбирает поправку к логиту, и её можно посчитать вручную на нескольких заказах.

Дерево как поправка к прогнозу

Пусть магазин предсказывает оценку отзыва в звёздах. Есть четыре условных заказа с оценками \(5,4,2,1\). Два первых доставили с небольшой задержкой, два последних — с большой. Если пока ничего не учитывать, лучший постоянный прогноз по квадратичной потере равен среднему \(3\). На первых двух заказах модель недооценила оценку, на последних переоценила.

Вычтем текущий прогноз из каждой оценки. Получатся остатки \(2,1,-1,-2\). Обучим маленькое регрессионное дерево предсказывать их по признакам заказа. Дереву достаточно одного вопроса о задержке, чтобы объединить заказы, которым нужна похожая поправка.

ЗадержкаОценкиОстатки при прогнозе \(3\)Поправка в листеНовый прогноз
Небольшая\(5,4\)\(2,1\)\(+1.5\)\(4.5\)
Большая\(2,1\)\(-1,-2\)\(-1.5\)\(1.5\)

В каждом листе дерево выдаёт среднее остатков. При полной поправке средняя квадратичная ошибка на этих четырёх заказах падает с \(2.5\) до \(0.25\). Теперь остатки равны \(0.5,-0.5,0.5,-0.5\). Внутри каждой группы по задержке они взаимно погашаются. Повтор того же вопроса дал бы нулевые поправки, а новый признак может разделить заказы с положительными и отрицательными остатками.

Обозначим текущий прогноз через \(F_{m-1}(x)\), а поправку из нового дерева через \(h_m(x)\). Умножим поправку на шаг обучения (learning rate) \(\nu\) и прибавим к прогнозу.

\[F_m(x)=F_{m-1}(x)+\nu h_m(x),\qquad F_M(x)=F_0(x)+\nu\sum_{m=1}^{M} h_m(x).\]

Это аддитивная модель (additive model). Для нового заказа мы проходим по ветвям каждого дерева и складываем числа из листьев. Остатки нужны при обучении, когда известна цель. Уже построенные деревья при добавлении следующего остаются фиксированными.

От остатков к градиенту

Для разных задач один и тот же числовой промах может стоить по-разному. При квадратичной потере крупную ошибку стоит исправлять сильнее. При абсолютной потере направление поправки определяется знаком ошибки, а её величина сама по себе не усиливает сигнал. Поэтому в общем случае вычисляем для каждого заказа псевдоостаток (pseudo-residual), то есть производную его потери по прогнозу со знаком минус.

\[r_i=-\left.\frac{\partial \ell(y_i,z)}{\partial z}\right|_{z=F_{m-1}(x_i)}.\]

Здесь \(x_i\) — признаки заказа, \(y_i\) — цель, \(z\) — число, которое выдала текущая модель. Положительный \(r_i\) предлагает увеличить \(z\), отрицательный — уменьшить. Для потери \(\ell(y,z)=\frac12(y-z)^2\) это в точности \(r_i=y_i-z\). Множитель \(\frac12\) убирает двойку при дифференцировании и сохраняет тот же минимум.

Если бы можно было менять ответ для каждого обучающего заказа по отдельности, хватило бы шага \(z_i\gets z_i+\nu r_i\). Чтобы поправка работала и на новых заказах, её задают функцией признаков. Дерево приближает нужные направления несколькими группами. Отсюда название градиентный спуск в пространстве функций (functional gradient descent). Каждый шаг добавляет к функции прогноза ещё одну функцию, выраженную деревом.

  1. Выбрать разбиения. Подать на регрессионное дерево признаки \(x_i\) и числовые цели \(r_i\). Разбиения оценивают по тому, насколько хорошо средние в листьях приближают псевдоостатки по квадратичной ошибке.
  2. Оценить поправки. Зафиксировать листья и подобрать для каждого общий сдвиг прогноза по исходной потере \(\ell\). При квадратичной потере он уже равен среднему остатков. Для других потерь можно решить одномерную задачу или взять приближённый шаг.
  3. Обновить ансамбль. Прибавить сдвиг из листа с коэффициентом \(\nu\). Следующее дерево получит псевдоостатки, пересчитанные после обновления.

Дерево и ансамбль решают разные задачи при обучении. Квадратичная ошибка дерева помогает выбрать группы заказов с похожими поправками. Исходная потеря ансамбля определяет, какие поправки нужны и какое значение записать в каждый лист.

Два шага на негативных отзывах

Сначала логит, затем вероятность

Теперь \(y=1\) означает негативный отзыв, \(y=0\) — его отсутствие. Как и в логистической регрессии, модель выдаёт логит \(F(x)\), а вероятность получается после сигмоиды \(p=\sigma(F)=1/(1+\exp(-F))\). Так можно прибавлять к логиту любые вещественные поправки и получать вероятность между нулём и единицей. Потеря одного заказа и псевдоостаток имеют вид

\[\ell(y,F)=\log(1+\exp(F))-yF,\qquad r=y-p.\]

Заказ с негативным отзывом и низкой оценкой \(p=0.1\) получает \(r=0.9\). Тот же класс при \(p=0.9\) даёт \(r=0.1\). Первая ошибка требует сильнее поднять логит. При \(y=0\) псевдоостаток равен \(-p\), поэтому высокая оценка негатива даёт сильный сигнал в другую сторону.

Начальная константа должна давать вероятность, равную доле негативных отзывов \(\bar y\). Это минимум log-loss среди постоянных прогнозов, если представлены оба класса. Соответствующий логит равен \(F_0=\log\bigl(\bar y/(1-\bar y)\bigr)\). В наших восьми заказах четыре негативных, поэтому \(F_0=0\) и \(p_0=0.5\) для всех.

ЗадержкаЦенаЗаказыНегативные отзывы
До четырёх дней включительноДо \(20\) тыс. ₽1 и 3\(0\) из \(2\)
До четырёх дней включительноВыше \(20\) тыс. ₽2 и 4\(1\) из \(2\), заказ 4
Больше четырёх днейДо \(20\) тыс. ₽5, 7 и 8\(2\) из \(3\), заказы 7 и 8
Больше четырёх днейВыше \(20\) тыс. ₽6\(1\) из \(1\)

Для ручного расчёта признаки уже разбиты на две категории, а у дерева ровно один вопрос. Сравниваем два возможных разбиения по средней квадратичной ошибке приближения псевдоостатков. Ошибку считаем по всем восьми заказам, подставляя в каждом листе своё среднее \(r_i\).

Первое дерево делит по задержке

В начале \(r_i\) равен \(+0.5\) у негативных отзывов и \(-0.5\) у остальных. В группах по задержке доли негатива составляют \(1/4\) и \(3/4\), а средние псевдоостатки равны \(-0.25\) и \(+0.25\). В первом листе три остатка отстоят от среднего на \(0.25\), один — на \(0.75\). Сумма квадратов отклонений равна \(3\cdot0.25^2+0.75^2=0.75\). Во втором листе получается столько же. Средняя ошибка по восьми заказам равна \(1.5/8=0.1875\). Для разбиения по цене такой же расчёт даёт \(0.2333\). Выбираем задержку.

Остаётся решить, на сколько сдвинуть логиты в каждом листе. Сдвиг \(\gamma\) прибавится ко всем логитам группы. В классическом алгоритме для log-loss используют один шаг Ньютона, который учитывает как направление изменения потери, так и её локальную кривизну.

\[\gamma_R\approx\frac{\sum_{i\in R}(y_i-p_i)}{\sum_{i\in R} p_i(1-p_i)}.\]

В числителе стоит суммарное требуемое изменение в листе \(R\). Знаменатель измеряет кривизну log-loss по общему сдвигу. Он переводит сигнал из числителя в размер поправки к логиту. В каждом листе первого дерева знаменатель равен \(4\cdot0.5\cdot0.5=1\). Суммы псевдоостатков равны \(-1\) и \(+1\), поэтому значения листьев получаются \(-1\) и \(+1\).

Вывод поправки Ньютона

Для заказа с текущим логитом \(F_i\) первая производная log-loss по этому логиту равна \(p_i-y_i\), поскольку производная \(\log(1+\exp F_i)\) равна \(\sigma(F_i)\). Вторая производная равна \(p_i(1-p_i)\), производной сигмоиды. Начальную константу получаем из того же правила. При одинаковом \(p\) у всех заказов сумма производных равна \(np-\sum_i y_i\) и обращается в ноль при \(p=\bar y\).

В листе сложим потери после общего сдвига \(L_R(\gamma)=\sum_{i\in R}\ell(y_i,F_i+\gamma)\). Около нулевого сдвига приближаем эту сумму параболой.

\[L_R(\gamma)\approx L_R(0)+L_R'(0)\gamma+\tfrac12 L_R''(0)\gamma^2.\]

В минимуме параболы её наклон равен нулю. Решая \(L_R'(0)+L_R''(0)\gamma=0\), получаем \(\gamma=-L_R'(0)/L_R''(0)\). Подстановка производных даёт формулу листа. Если взять среднее потерь внутри листа, общий множитель \(1/|R|\) сократится.

Шаг Ньютона приближённый. В первом дереве точный минимум для листа с долей негатива \(1/4\) и исходным логитом \(0\) достигается при \(\gamma=-\log 3\approx-1.099\). Один шаг даёт близкое значение \(-1\). В чистом листе без ограничений log-loss стремится к минимуму при бесконечном логите, поэтому конечная поправка Ньютона тоже имеет смысл.

Возьмём \(\nu=0.5\), чтобы было удобно считать. После первого дерева логиты равны \(-0.5\) при небольшой задержке и \(+0.5\) при большой. Вероятности становятся \(0.378\) и \(0.622\). Например, у заказа 4 был негативный отзыв, а модель снизила его вероятность до \(0.378\). Теперь он подаёт более сильный сигнал \(r\approx0.622\), чем на старте.

Второе дерево делит по цене

После пересчёта \(r_i\) ошибка приближения остатка разбиением по задержке равна \(0.1875\), а по цене — \(0.1779\). Теперь лучше цена. У дорогих заказов 2, 4 и 6 сумма псевдоостатков составляет \(0.6225\), а сумма кривизн — \(0.7050\). Значение листа близко к \(+0.883\), поэтому к логиту каждого дорогого заказа прибавляется \(0.441\). В другом листе сумма псевдоостатков равна \(-0.6225\), сумма кривизн — \(1.1750\), а прибавка к логиту — около \(-0.265\).

У заказа 4 вероятность поднимается до \(0.485\). У заказа 5, который долго ждал доставку, но не оставил негативный отзыв, она опускается с \(0.622\) до \(0.559\). Оба прогноза стали ближе к меткам, хотя порог \(0.5\) пока оставил решения прежними. Средняя log-loss на восьми обучающих заказах меняется как \(0.693\to0.599\to0.558\).

Другие потери и несколько классов

Регрессия с выбросами и несимметричной ценой ошибки

В регрессии прогноз \(F\) измеряется в единицах цели. Пусть \(e=y-F\) — остаток. Выбор потери меняет сигнал для разбиений и окончательное значение листа. Например, при MAE дерево ищет группы с одинаковым направлением ошибки, а затем подбирает размер поправки по фактическим остаткам в каждой группе.

ПотеряЦель для разбиений дереваСдвиг, минимизирующий потерю в листе
Квадратичная \(\tfrac12e^2\)\(e\)Среднее остатков
Абсолютная \(|e|\)\(\operatorname{sign}(e)\)Медиана остатков
Хьюбера (Huber loss)Остаток, ограниченный интервалом \([-\delta,\delta]\)Одномерный минимум потери Хьюбера по сдвигу
Квантильная (pinball loss)\(\tau\) при \(e>0\), \(\tau-1\) при \(e<0\)\(\tau\)-квантиль остатков, \(0<\tau<1\)

В точке \(e=0\) для абсолютной и квантильной потерь можно взять субградиент \(0\). Для сравнения пусть в одном листе остатки \(1,2,15\) дней. По квадратичной потере поправка равна \(6\) дням, по абсолютной — \(2\). Потеря Хьюбера ограничивает влияние большого промаха на направление шага. Квантильную потерю можно использовать, если нужен срок, до которого заказ доедет с заданной вероятностью. При \(\tau=0.9\) она штрафует недооценку срока в девять раз сильнее равноценной переоценки. Долю доставок, уложившихся в оценённый срок, проверяют на новых заказах.

По одному логиту на класс

Если отзыв может быть негативным, нейтральным или позитивным, модель хранит три логита. Для \(K\) взаимоисключающих классов вероятности получают через softmax, а цели для деревьев вычисляют по каждому классу.

\[p_{ik}=\frac{\exp(F_k(x_i))}{\sum_{j=1}^{K}\exp(F_j(x_i))},\qquad r_{ik}=y_{ik}-p_{ik},\]

где \(y_{ik}=1\) только у истинного класса заказа \(i\). В классической схеме на одной итерации строят по одному регрессионному дереву на класс. Все псевдоостатки вычисляют из одних и тех же вероятностей до обновления. При этом изменение логита одного класса влияет на вероятности всех остальных через знаменатель softmax.

Формула листа для нескольких классов

У Фридмана в алгоритме \(L_K\)-TreeBoost (2001, алгоритм 6) логиты стартуют с нуля. Для поправки он использует диагональное приближение матрицы вторых производных с учётом ограничения на сумму логитов. Для листа \(R\) дерева класса \(k\) получается

\[\gamma_{k,R}\approx\frac{K-1}{K}\frac{\sum_{i\in R}(y_{ik}-p_{ik})}{\sum_{i\in R}p_{ik}(1-p_{ik})}.\]

В записи статьи знаменатель выражен через \(|r_{ik}|(1-|r_{ik}|)\). При \(y_{ik}=0\) модуль равен \(p_{ik}\), при \(y_{ik}=1\) — \(1-p_{ik}\). В обоих случаях произведение одинаково. Множитель \((K-1)/K\) относится к этому приближению. В бинарной постановке с одним логитом из примера выше используется формула без него.

Шаг, глубина и число деревьев

Шаг обучения. Уменьшение вклада каждого дерева называют сжатием шага (shrinkage). Меньший \(\nu\) обычно требует больше деревьев. Эти настройки работают вместе. Если уменьшить \(\nu\) вдвое и удвоить число деревьев, получатся другие прогнозы, поскольку после каждого обновления изменятся псевдоостатки и следующие разбиения.

Глубина и размер листа. Одно дерево с одним вопросом добавляет поправку по одному признаку. Чтобы поправка за высокую цену зависела от задержки, дереву нужен путь, на котором встречаются оба признака. Глубина позволяет учесть такие взаимодействия, а слишком маленькие листья подстраиваются под отдельные случаи. Для log-loss малая сумма \(p_i(1-p_i)\) в листе также может сделать шаг Ньютона слишком большим. Ограничение сложности и небольшой шаг снижают этот риск.

Число итераций. С добавлением деревьев ансамбль может всё лучше подгонять обучающие остатки, в том числе шум. Когда ошибка на валидации перестаёт улучшаться, полезно выбрать более раннюю итерацию. Это ранняя остановка (early stopping). Отдельный тест используется для проверки уже выбранной модели.

Случайная подвыборка. В стохастическом градиентном бустинге (stochastic gradient boosting) на каждом шаге выбирают часть строк без возвращения. Новое дерево и его поправки строятся по этой подвыборке. Можно также ограничивать признаки на дерево, уровень или узел в зависимости от реализации. Сэмплирование добавляет разнообразие и может ускорить обучение, но слишком маленькая подвыборка лишает дерево полезного сигнала. См. Friedman, 2002.

Как сюда относится AdaBoost

Бинарный дискретный AdaBoost тоже добавляет модели по одной. На очередном шаге классификатор обучают с весами объектов, затем добавляют его взвешенный голос. Friedman, Hastie и Tibshirani показали, что эту схему можно представить как поэтапную минимизацию экспоненциальной потери \(\exp(-yS(x))\), где \(y\in\{-1,+1\}\), а \(S(x)\) — сумма взвешенных голосов. См. Friedman, Hastie, Tibshirani, 2000.

При уверенной ошибке \(yS(x)\) становится большим отрицательным числом, и вес этого заказа растёт экспоненциально. Поэтому ошибочная метка, которую трудно согласовать с остальными данными, может перетянуть внимание AdaBoost на себя. Для log-loss сигнал \(y-p\) по модулю ограничен единицей. Выбор потери влияет на то, как сильно каждый такой пример потянет следующий шаг.

На практике

В scikit-learn 1.9.1 GradientBoostingClassifier реализует классический бустинг на регрессионных деревьях. В примере \(X_{\text{train}}\) и \(X_{\text{test}}\) содержат признаки заказов, а метки закодированы нулями и единицами. Для независимых заказов используем внутреннюю стратифицированную валидацию при обучении. Параметры примера задают неглубокие деревья, небольшой шаг и верхний предел числа итераций. См. документацию классификатора.

from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import log_loss

model = GradientBoostingClassifier(
    loss="log_loss",
    n_estimators=300,
    learning_rate=0.05,
    max_depth=2,
    min_samples_leaf=10,
    validation_fraction=0.15,
    n_iter_no_change=15,
    random_state=42,
)
model.fit(X_train, y_train)

probabilities = model.predict_proba(X_test)
negative_index = list(model.classes_).index(1)
p_negative = probabilities[:, negative_index]

print("Число итераций:", model.n_estimators_)
print("Риск негатива для первого заказа:", p_negative[0])
print("Log-loss на тесте:", log_loss(y_test, probabilities, labels=model.classes_))

Для истории заказов с временной или групповой зависимостью подготовьте собственную валидацию. Можно сравнить прогнозы промежуточных итераций через staged_predict_proba(X_val) и обучить итоговую модель с выбранным числом итераций. Для регрессии аналогичный интерфейс даёт GradientBoostingRegressor. В нём доступны квадратичная, абсолютная, квантильная потери и потеря Хьюбера. См. документацию регрессора.

Ключевые статьи

  • Friedman. Greedy Function Approximation: A Gradient Boosting Machine, 2001 — градиентный бустинг как поэтапное построение аддитивной модели и формулы для деревьев.
  • Friedman. Stochastic Gradient Boosting, 2002 — случайные подвыборки без возвращения при построении очередного дерева.
  • Friedman, Hastie, Tibshirani. Additive Logistic Regression: A Statistical View of Boosting, 2000 — связь AdaBoost с аддитивной моделью и экспоненциальной потерей.
