В предыдущем разделе линейная модель дважды оказалась без надёжного решения: при коррелированных признаках веса неустойчивы, на разделимых данных MLE вообще не существует. Регуляризация добавляет к потере штраф за величину весов и обменивает немного смещения на большое уменьшение дисперсии. Ниже — L2 как штраф, как MAP и как сжатие по главным направлениям данных; L1 и причина, по которой она обнуляет веса; elastic net для групп коррелированных слов; путь регуляризации и выбор силы штрафа; ранняя остановка как неявная регуляризация. Сквозной пример — оценка отзыва в звёздах по словам текста.

Штраф за величину весов

Регуляризованная задача — минимизация суммы потери и штрафа с силой \(\lambda\ge0\):

\[\hat w_\lambda=\arg\min_w\;\sum_{i=1}^{n}\ell\big(y_i,\,w^\top x_i+b\big)+\lambda\,\Omega(w),\qquad \Omega(w)=\lVert w\rVert_2^2\ \text{(L2)},\quad \lVert w\rVert_1\ \text{(L1)}.\]

При \(\lambda=0\) это исходная задача, при \(\lambda\to\infty\) все веса стремятся к нулю и модель предсказывает константу. Между ними \(\lambda\) двигает компромисс из раздела об обобщении: смещение растёт, дисперсия падает. Два правила, о которых спрашивают отдельно:

  • Свободный член не штрафуют. Сдвиг всех \(y\) на константу должен сдвигать прогноз, а не менять штраф. Штраф на \(b\) тянет средний прогноз к нулю. В scikit-learn его штрафует только решатель liblinear у логистической регрессии.
  • Штраф зависит от масштаба. Если цену перевести из рублей в тысячи рублей, вес вырастет в тысячу раз, и тот же \(\lambda\) оштрафует его в миллион раз сильнее. Поэтому плотные признаки стандартизуют перед регуляризованными моделями. Для разреженного TF-IDF центрирование уничтожает разреженность: строки нормируют, а при масштабировании столбцов не центрируют.

L2: сжатие, обусловленность, MAP

Для квадратичной потери (ridge-регрессия) решение явное:

\[\hat w_\lambda=(X^\top X+\lambda I)^{-1}X^\top y.\]

Матрица \(X^\top X+\lambda I\) обратима при любом \(\lambda>0\): её собственные числа сдвинуты на \(\lambda\), число обусловленности \(\frac{d_1^2+\lambda}{d_d^2+\lambda}\) конечно даже при коллинеарных признаках. Через SVD \(X=UDV^\top\) видно, что именно сжимает ridge:

\[X\hat w_\lambda=\sum_{j}u_j\,\frac{d_j^2}{d_j^2+\lambda}\,u_j^\top y,\qquad \operatorname{df}(\lambda)=\sum_j\frac{d_j^2}{d_j^2+\lambda}.\]

Направления с большой дисперсией данных (\(d_j^2\gg\lambda\)) почти не трогаются, направления с малой — подавляются. Это как раз те направления, по которым оценка весов неустойчива: разность двух почти одинаковых признаков. \(\operatorname{df}(\lambda)\) — эффективное число параметров: от \(d\) при \(\lambda=0\) до нуля.

MAP. При \(y\mid w\sim\mathcal N(Xw,\sigma^2I)\) и априорном \(w\sim\mathcal N(0,\tau^2I)\) минус логарифм апостериорной плотности с точностью до константы равен \(\frac{1}{2\sigma^2}\lVert y-Xw\rVert^2+\frac{1}{2\tau^2}\lVert w\rVert^2\), то есть ridge с \(\lambda=\sigma^2/\tau^2\). Широкое априорное распределение — слабый штраф. Связь MLE и MAP — в справочнике.

L2 не обнуляет веса: производная штрафа \(2\lambda w_j\) исчезает вблизи нуля, и при любом ненулевом градиенте потери вес остаётся ненулевым. Одинаковые признаки ridge делит поровну — так в примере со словом «сломался» из предыдущего раздела сумма весов делилась на две равные части.

L1: почему веса становятся нулями

Лассо (lasso) штрафует сумму модулей. Возьмём масштаб, как в scikit-learn: \(\frac{1}{2n}\lVert y-Xw\rVert^2+\alpha\lVert w\rVert_1\). Штраф не дифференцируем в нуле, условие оптимума записывают через субградиент:

\[\tfrac1n x_j^\top(y-X\hat w)=\alpha\operatorname{sign}(\hat w_j)\ \ \text{при}\ \hat w_j\ne0,\qquad \big\lvert\tfrac1n x_j^\top(y-X\hat w)\big\rvert\le\alpha\ \ \text{при}\ \hat w_j=0.\]

Признак входит в модель только тогда, когда его корреляция с остатком превышает \(\alpha\); иначе его вес — точный ноль. Отсюда же \(\alpha_{\max}=\max_j\frac1n\lvert x_j^\top y\rvert\) для центрированных данных: при \(\alpha\ge\alpha_{\max}\) все веса нулевые. Причина в форме штрафа: его производная по модулю равна \(\alpha\) при сколь угодно малом весе, и пока градиент потери слабее, штраф удерживает вес в нуле.

Геометрия. Штрафованная задача эквивалентна ограниченной: минимизировать потерю при \(\Omega(w)\le t\). Решение — точка, где линия уровня потери впервые касается допустимой области. У L2-круга граница гладкая, и касание почти никогда не попадает на ось. У L1-ромба углы лежат на осях, и эллипс часто касается именно угла.

Ортонормированные признаки (\(X^\top X=nI\)) дают явные формулы через коэффициент без штрафа \(z_j\). Если все штрафы записать к потере \(\frac{1}{2n}\lVert y-Xw\rVert^2\), то ridge с \(\frac{\lambda}{2}\lVert w\rVert_2^2\) делит \(z_j\) на \(1+\lambda\), лассо с \(\lambda\lVert w\rVert_1\) применяет мягкий порог (soft-thresholding) \(\operatorname{sign}(z_j)(\lvert z_j\rvert-\lambda)_+\), а отбор лучшего подмножества со штрафом \(\lambda_0\lVert w\rVert_0\) (число ненулевых весов) — жёсткий порог \(\sqrt{2\lambda_0}\). L0 — комбинаторная невыпуклая задача; L1 — её ближайшая выпуклая замена.

Общий случай решают покоординатным спуском: для каждого \(j\) по очереди считают корреляцию признака с частичным остатком (без вклада самого \(j\)) и применяют к ней мягкий порог. Каждый шаг — точная минимизация по одной координате, задача выпукла, и с тёплым стартом по убывающей сетке \(\alpha\) весь путь считается почти за цену одного решения (Friedman et al., 2010). При \(d>n\) лассо оставляет не больше \(n\) ненулевых весов (при данных в общем положении).

MAP. Априорное распределение Лапласа \(p(w_j)\propto e^{-\lvert w_j\rvert/b}\) даёт L1-штраф; его острый пик в нуле и делает нулевую оценку наиболее вероятной.

Коррелированные признаки и elastic net

Из группы сильно коррелированных признаков лассо обычно берёт один, а какой именно — зависит от мелких особенностей выборки. В примере ниже слова «брак» и «бракованный» встречаются почти всегда вместе (корреляция \(0.94\)) и в модели, по которой сгенерированы данные, влияют на оценку одинаково. Лассо долго держит только «бракованный»: его вес по модулю в середине пути даже больше, чем без штрафа (\(-0.41\) против \(-0.35\)), — он забирает вклад обоих слов. Набор отобранных слов поэтому неустойчив к пересэмплированию.

Elastic net складывает оба штрафа: в scikit-learn \(\frac{1}{2n}\lVert y-Xw\rVert^2+\alpha\rho\lVert w\rVert_1+\frac{\alpha(1-\rho)}{2}\lVert w\rVert_2^2\), где \(\rho\) — l1_ratio. L2-часть делает задачу строго выпуклой: решение единственно, одинаковые признаки получают одинаковые веса, а сильно коррелированные — близкие (grouping effect, Zou & Hastie, 2005). L1-часть сохраняет разреженность. Для текстов с синонимами и словоформами это частый выбор, если нужен отбор слов.

Путь регуляризации и выбор силы штрафа

Путь регуляризации (regularization path) — веса как функция силы штрафа. Условный пример: \(60\) отзывов, оценка в звёздах сгенерирована как линейная функция шести слов с шумом; «курьер» на оценку не влияет. Признаки стандартизованы, свободный член не штрафуется.

Силу штрафа выбирают по validation или кросс-валидации по сетке значений на логарифмической шкале — со всеми оговорками раздела о валидации. Распространённая эвристика — правило одной стандартной ошибки: взять самую сильную регуляризацию, качество которой отличается от лучшего меньше чем на стандартную ошибку оценки (ESL, гл. 7.10). Модель проще при практически том же качестве.

Ранняя остановка

Градиентный спуск из нуля с шагом \(\eta\) на \(\frac12\lVert y-Xw\rVert^2\) в базисе SVD сходится по каждому направлению независимо. После \(t\) шагов компонента решения вдоль \(v_j\) равна доле решения OLS; сравним эту долю с ridge:

\[\text{GD:}\ \ 1-(1-\eta d_j^2)^{t},\qquad \text{ridge:}\ \ \frac{d_j^2}{d_j^2+\lambda}.\]

Оба множителя близки к единице для направлений с большой \(d_j^2\) и малы для слабых, так что остановка после \(t\) шагов действует примерно как ridge с \(\lambda\sim1/(\eta t)\). Это точное утверждение только для квадратичной потери и спуска из нуля; для логистической потери, бустинга и нейросетей сходство качественное. Число шагов, как и \(\lambda\), выбирают по validation; в бустинге и нейросетях ранняя остановка — основной регулятор ёмкости.

В SGD без инерции L2-штраф в потере совпадает с уменьшением весов (weight decay) на каждом шаге. В адаптивных оптимизаторах это уже не так — разница L2 и weight decay в Adam разобрана в справочнике Adam и AdamW.

На практике

Мягкий порог и дублированный признак без библиотек

Два одинаковых центрированных признака, \(\frac1n\lVert x\rVert^2=1\). Лассо отдаёт весь вес первому признаку, ridge делит поровну; суммы весов почти совпадают.

def soft_threshold(z, lam):
    return z - lam if z > lam else z + lam if z < -lam else 0.0

def lasso_cd(X, y, alpha, sweeps=100):
    """(1/2n)||y - Xw||^2 + alpha*||w||_1; столбцы центрированы, (1/n)||x_j||^2 = 1."""
    n, d = len(X), len(X[0])
    w = [0.0] * d
    for _ in range(sweeps):
        for j in range(d):
            partial = [y[i] - sum(X[i][k] * w[k] for k in range(d) if k != j) for i in range(n)]
            w[j] = soft_threshold(sum(X[i][j] * partial[i] for i in range(n)) / n, alpha)
    return w

x = [1, -1, 1, -1, 1, -1]
X = [[v, v] for v in x]                       # второй признак — копия первого
y = [2.1, -1.9, 1.8, -2.2, 2.0, -1.8]
print([round(v, 3) for v in lasso_cd(X, y, alpha=0.1)])
xty, lam = sum(a * b for a, b in zip(x, y)), 0.6
print([round(xty / (2 * len(x) + lam), 3)] * 2)   # ridge: (X^T X + lam I) w = X^T y
# [1.867, 0.0]
# [0.937, 0.937]

Код сверен с документацией scikit-learn 1.9.1, но не запускался. Тихие ошибки:

  • Масштаб alpha у оценщиков разный: Ridge минимизирует \(\lVert y-Xw\rVert^2+\alpha\lVert w\rVert^2\) без деления на \(n\), а Lasso и ElasticNet делят потерю на \(2n\). Одно и то же число означает разную силу штрафа, а у Ridge при росте выборки штраф относительно потери слабеет.
  • У LogisticRegression регуляризацию задаёт C — обратная сила: больше C, слабее штраф. Тип штрафа задаёт l1_ratio, параметр penalty устарел.
  • RidgeCV без cv выбирает \(\alpha\) по эффективной формуле leave-one-out для линейных сглаживателей — это не k-fold, и групповое разбиение он не учтёт.
  • StandardScaler на разреженной матрице требует with_mean=False: центрирование уничтожило бы разреженность, поэтому без этого флага он выдаёт ошибку.
  • Отобранный лассо набор слов не стоит читать как «важные слова»: из коррелированной группы выбор случаен. Устойчивость проверяют повторным отбором на бутстрэп-выборках (stability selection).
