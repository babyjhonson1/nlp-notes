Модель обучают минимизировать ошибку на обучающей выборке, а нужна ей малая ошибка на новых данных из того же распределения. Разрыв между этими величинами — переобучение (overfitting); его размер определяется ёмкостью модели, объёмом данных и шумом. Ниже — постановка через истинный и эмпирический риск, ёмкость на примере kNN, разложение bias–variance с условиями, при которых оно верно, диагностика по кривым обучения, проклятие размерности и double descent. Регуляризация, ансамбли деревьев и выбор модели по валидации в следующих разделах управляют этим же компромиссом.

Истинный и эмпирический риск

Пары \((x,y)\) приходят из неизвестного распределения \(P\), \(\ell(y,\hat y)\) — функция потерь, \(f\) — модель. Истинный риск (true risk) — ожидаемая потеря на новом примере, эмпирический (empirical risk) — средняя потеря на обучающей выборке \(D=\{(x_i,y_i)\}_{i=1}^{n}\):

\[R(f)=\mathbb E_{(x,y)\sim P}\,\ell\big(y,f(x)\big),\qquad \hat R_D(f)=\frac1n\sum_{i=1}^{n}\ell\big(y_i,f(x_i)\big).\]

Обучение — минимизация эмпирического риска (empirical risk minimization, ERM) по классу моделей \(\mathcal F\): \(\hat f=\arg\min_{f\in\mathcal F}\hat R_D(f)\). Для модели, выбранной без взгляда на \(D\), \(\hat R_D(f)\) — несмещённая оценка \(R(f)\). Для \(\hat f\) это неверно: её выбрали по тем же данным, на которых оценивают. Пусть \(f^*=\arg\min_{f\in\mathcal F}R(f)\) — лучшая модель класса; от \(D\) она не зависит. Тогда

\[\mathbb E_D\,\hat R_D(\hat f)\;\le\;\mathbb E_D\,\hat R_D(f^*)\;=\;R(f^*)\;\le\;\mathbb E_D\,R(\hat f).\]

Первое неравенство — определение ERM, второе — определение \(f^*\). Ошибка на обучении в среднем занижена. Неравенство не говорит, насколько; на практике разрыв растёт с ёмкостью, когда класс способен подстроиться под шум конкретной выборки.

Наименьший риск среди всех измеримых функций \(R^*=\inf_f R(f)\) называют байесовским (Bayes risk). Он больше нуля, если \(y\) не определяется по \(x\) однозначно: одинаковые признаки, разные метки. Избыточный риск обученной модели раскладывается на две части:

\[R(\hat f)-R^*=\underbrace{R(\hat f)-R(f^*)}_{\text{ошибка оценивания}}+\underbrace{R(f^*)-R^*}_{\text{ошибка аппроксимации}}.\]

Расширение \(\mathcal F\) не увеличивает ошибку аппроксимации, но при фиксированном \(n\) обычно увеличивает ошибку оценивания. Это общая форма компромисса; разложение bias–variance ниже — его аналог для квадратичной потери, усреднённый по обучающим выборкам.

Переобучение: ошибка на обучении мала, а истинный риск заметно выше достижимого — модель выучила шум выборки. Недообучение (underfitting): обе ошибки высоки и близки — класс не выражает зависимость. \(R\) неизвестен, поэтому его оценивают на отложенных данных; как делать это без смещения — тема следующего раздела о валидации.

Ёмкость на примере kNN

Метод \(k\) ближайших соседей (k-nearest neighbors, kNN) параметров не обучает. Для нового \(x\) он находит \(k\) ближайших обучающих точек \(N_k(x)\) и усредняет их метки (в классификации — голосует): \(\hat f_k(x)=\frac1k\sum_{i\in N_k(x)}y_i\). Ёмкостью управляет одно число.

  • При \(k=1\) каждая обучающая точка — свой ближайший сосед, и ошибка на обучении нулевая, если нет совпадающих \(x\) с разными метками. Граница огибает каждую зашумлённую метку.
  • С ростом \(k\) усреднение идёт по большей окрестности и сглаживает границу. При \(k=n\) модель везде предсказывает самый частый класс.
  • Грубая мера ёмкости — эффективное число параметров \(n/k\): столько непересекающихся окрестностей помещается в выборке (ESL, гл. 2.3).

На этих данных минимум ошибки на validation, около \(16\%\), достигается при \(k\) от \(5\) до \(13\); байесовская ошибка, оценённая на тех же 1500 точках, — около \(14.5\%\). При \(k=1\) ошибка на validation \(25.9\%\). Для сравнения, асимптотический результат Cover & Hart (1967): для двух классов при \(n\to\infty\) и мягких условиях на распределение ошибка 1-NN лежит между \(R^*\) и \(2R^*(1-R^*)\), здесь это около \(24.8\%\). При \(n=100\) до асимптотики далеко, и наблюдаемая ошибка эту границу слегка превышает.

Две практические особенности kNN, о которых спрашивают отдельно. Метод опирается на расстояние, поэтому признаки нужно приводить к одному масштабу: признак в рублях задавит признак в долях. Обучение — это хранение выборки, а предсказание стоит \(O(nd)\) на запрос при полном переборе; на больших коллекциях используют приближённый поиск, разобранный в разделе ANN.

Разложение bias–variance

Условия и формула

Пусть \(y=f(x)+\varepsilon\), где \(\mathbb E\varepsilon=0\), \(\operatorname{Var}\varepsilon=\sigma^2\), а шум нового примера не зависит от обучающей выборки \(D\). Модель \(\hat f_D\) обучена на случайной выборке размера \(n\); средний по выборкам прогноз в точке \(x_0\) — \(\bar f(x_0)=\mathbb E_D\hat f_D(x_0)\), метка нового примера — \(y_0=f(x_0)+\varepsilon\). Для фиксированного \(x_0\) и квадратичной потери

\[\mathbb E_{D,\varepsilon}\big(y_0-\hat f_D(x_0)\big)^2=\underbrace{\sigma^2}_{\text{шум}}+\underbrace{\big(f(x_0)-\bar f(x_0)\big)^2}_{\text{bias}^2}+\underbrace{\mathbb E_D\big(\hat f_D(x_0)-\bar f(x_0)\big)^2}_{\text{variance}}.\]

Вывод: \(y_0-\hat f_D=\varepsilon+(f-\bar f)+(\bar f-\hat f_D)\). При возведении в квадрат перекрёстные члены зануляются: \(\varepsilon\) не зависит от \(D\) и имеет нулевое среднее, а \(\mathbb E_D(\bar f-\hat f_D)=0\) по определению \(\bar f\). Ожидаемую ошибку на всём распределении получают усреднением по \(x_0\).

Bias и variance — свойства процедуры обучения при данном \(n\), а не одной обученной модели: обе величины — ожидания по воображаемым повторениям выборки. По одной выборке их не измерить, только оценить симуляцией или бутстрэпом. Шум \(\sigma^2\) не убирается никакой моделью: для квадратичной потери это и есть байесовский риск.

Пример: kNN-регрессия

Для kNN разложение выписывается явно, если считать входы обучения фиксированными, а случайными — только шумы меток (ESL, формула 7.10). Пусть \(x_{(l)}\) — \(l\)-й ближайший к \(x_0\) обучающий вход. Прогноз — среднее \(k\) независимых меток, поэтому дисперсия равна \(\sigma^2/k\):

\[\mathbb E\big(y_0-\hat f_k(x_0)\big)^2=\sigma^2+\Big(f(x_0)-\frac1k\sum_{l=1}^{k}f(x_{(l)})\Big)^2+\frac{\sigma^2}{k}.\]

Рост \(k\) уменьшает дисперсию, но добавляет в среднее всё более далёких соседей, у которых \(f\) другое, — растёт смещение. Условный пример: \(f(x)=x^2\), обучающие входы \(x_i\in\{-3,\dots,3\}\), \(x_0=0.2\), \(\sigma^2=2\). Соседи по удалению: \(0,1,-1,2,-2\) со значениями \(f\): \(0,1,1,4,4\).

\(k\)Среднее \(f\) соседей\(\text{bias}^2\)\(\text{variance}=\sigma^2/k\)\(\text{bias}^2+\text{variance}\)
\(1\)\(0\)\(0.0016\)\(2\)\(2.0016\)
\(2\)\(0.5\)\(0.2116\)\(1\)\(1.2116\)
\(3\)\(0.667\)\(0.3927\)\(0.6667\)\(1.0594\)
\(4\)\(1.5\)\(2.1316\)\(0.5\)\(2.6316\)
\(5\)\(2\)\(3.8416\)\(0.4\)\(4.2416\)

Минимум при \(k=3\). При \(k=4\) в среднее входит сосед \(x=2\) со значением \(4\), и квадрат смещения скачком растёт с \(0.39\) до \(2.13\). К каждой строке добавляется неустранимое \(\sigma^2=2\).

Если усреднить ту же формулу по всем точкам \(x_0\) гладкой функции и пройти все \(k\) от \(n\) до \(1\), получается классическая U-образная кривая.

Для классификации формула не переносится

С 0–1 потерей аддитивного аналога нет: ошибка зависит от того, по какую сторону порога оказался прогноз, а не от квадрата отклонения. Предложено несколько несовместимых определений bias и variance. В разложении Domingos (2000) для двух классов дисперсия в точках, где основной (самый частый по выборкам) прогноз не совпадает с байесовским, входит со знаком минус: разброс иногда переводит ответ на правильную сторону. Поэтому интуицию «дисперсия всегда добавляет ошибку» в классификацию напрямую не переносят.

Какие ручки что двигают

Таблица — частый вопрос на собеседовании. Первые четыре строки следуют из формул выше или из явного вида модели; строки про ансамбли — эвристики, которые подробно разобраны в разделах о лесе и бустинге.

Отсюда ответ на вопрос «почему лес строят из глубоких деревьев, а бустинг — из неглубоких». Лес усредняет модели с низким смещением и высокой дисперсией и гасит дисперсию; усреднение смещение не уменьшает, поэтому базовые деревья должны быть точными. Бустинг последовательно суммирует слабые модели с высоким смещением и снижает его; глубокие деревья в бустинге быстро подгоняют шум. Это эвристика, а не теорема.

Диагностика: кривые обучения и что делать

Кривая валидации (validation curve) — ошибки на train и validation в зависимости от ёмкости при фиксированном \(n\), как на графике в иллюстрации выше. Кривая обучения (learning curve) — те же ошибки в зависимости от \(n\) при фиксированной модели. С ростом \(n\) ошибка на обучении обычно растёт (выборку труднее запомнить), а на validation падает; кривые сближаются. По тому, где и как они сходятся, видно, поможет ли больше данных.

СимптомДиагнозЧто пробовать
Ошибка на обучении низкая, на validation заметно выше; разрыв сокращается с ростом \(n\)Высокая дисперсияБольше данных; регуляризация; проще модель (меньше глубина, больше \(k\)); бэггинг; ранняя остановка; отбор признаков
Обе ошибки высокие, близки друг к другу и вышли на платоВысокое смещениеБольше данных того же вида не поможет. Нужны ёмкость, новые признаки, меньше регуляризации, бустинг или другая модель
Ошибка на validation ниже, чем на обученииСкорее свойство разбиения, чем моделиМаленькая или более лёгкая validation, утечка, аугментации и шум только в train. Проверить разбиение

Сам разрыв между train и validation — не критерий вреда. Лес из глубоких деревьев имеет почти нулевую ошибку на обучении и часто при этом лучшую на validation, чем у одиночного дерева. Решает ошибка на отложенных данных, а не разница двух чисел. На маленькой validation обе кривые шумные: различие в пару процентов может быть случайным, как в правой части иллюстрации.

Проклятие размерности

Методы, опирающиеся на локальность (kNN, ядровые оценки), в высокой размерности теряют её по двум причинам.

Окрестности перестают быть локальными. Для равномерных данных в единичном кубе \([0,1]^d\) подкуб, содержащий долю \(r\) точек, имеет ребро \(r^{1/d}\). При \(d=10\) для \(r=0.01\) ребро \(0.63\), для \(r=0.1\) — \(0.79\) (пример ESL, гл. 2.5). Чтобы собрать \(1\%\) данных, «окрестность» должна покрыть почти две трети диапазона каждого признака, и усреднение по ней уже не локально — растёт смещение.

Расстояния концентрируются. Для независимых равномерных \(x,x'\in[0,1]^d\) квадрат расстояния \(\|x-x'\|^2=\sum_j\Delta_j^2\) — сумма \(d\) независимых слагаемых со средним \(1/6\) и дисперсией \(7/180\). Отсюда

\[\frac{\operatorname{sd}\|x-x'\|^2}{\mathbb E\|x-x'\|^2}=\frac{\sqrt{7d/180}}{d/6}=\sqrt{\frac{7}{5d}}.\]

Относительный разброс \(0.84\) при \(d=2\), \(0.12\) при \(d=100\), \(0.043\) при \(d=768\). Ближайший и самый дальний соседи становятся почти равноудалены, и порядок соседей определяется мелкими различиями. Beyer et al. (1999) формулируют общее условие: если относительный разброс расстояний стремится к нулю с ростом размерности, отношение расстояний до самой дальней и самой близкой точки из конечного набора стремится к единице по вероятности.

Результат получен для независимых, одинаково распределённых координат. Эмбеддинги текстов имеют сотни измерений, а поиск соседей по ним на практике работает: координаты сильно зависимы, данные сосредоточены вблизи структур гораздо меньшей внутренней размерности (intrinsic dimension). Правильный вывод — не «kNN в 768 измерениях бесполезен», а «качество определяется внутренней размерностью и структурой данных, а не числом координат».

Double descent

Классическая картина — U-образная ошибка на тесте в зависимости от ёмкости. Belkin et al. (2019) показали эмпирически, что если продолжать увеличивать ёмкость за порог интерполяции — точку, где модель впервые точно подгоняет всю обучающую выборку, — ошибка на тесте после пика снова снижается. Это наблюдали на random Fourier features, полносвязных сетях и ансамблях деревьев; Nakkiran et al. (2019) — на глубоких сетях, в том числе по числу эпох, и показали, что вблизи порога даже рост объёма данных может ухудшить результат.

  • Пик — около порога, где число параметров сравнимо с числом точек: интерполирующее решение почти единственно, плохо обусловлено и сильно реагирует на шум меток.
  • За порогом интерполирующих решений много, и алгоритм выбирает одно определённое: например, для линейной регрессии псевдообратная матрица и градиентный спуск из нуля дают решение с минимальной нормой. Это неявная регуляризация.
  • Высота пика зависит от шума и регуляризации. Для ряда линейных постановок доказано, что оптимально подобранная L2-регуляризация убирает пик (Nakkiran et al., 2021).

Пик и второй спуск можно получить точно, без нейросетей, на линейной регрессии с гауссовскими признаками (Belkin, Hsu, Xu, 2020).

Double descent не опровергает разложение bias–variance: это тождество. Неверной оказывается эвристика «больше параметров — больше дисперсия». Для моделей этой главы рабочий инструмент прежний — кривая валидации по параметру ёмкости.

На практике

Проверяемый расчёт таблицы bias–variance

Код воспроизводит таблицу kNN-регрессии из раздела о разложении: только стандартная библиотека, без обучения моделей.

def knn_bias_variance(f, xs, x0, sigma2, k):
    nearest = sorted(xs, key=lambda x: abs(x - x0))[:k]
    mean_f = sum(f(x) for x in nearest) / k
    return (f(x0) - mean_f) ** 2, sigma2 / k

f = lambda x: x * x
for k in range(1, 6):
    bias2, var = knn_bias_variance(f, range(-3, 4), x0=0.2, sigma2=2.0, k=k)
    print(k, round(bias2, 4), round(var, 4), round(bias2 + var, 4))
# 1 0.0016 2.0 2.0016
# 2 0.2116 1.0 1.2116
# 3 0.3927 0.6667 1.0594
# 4 2.1316 0.5 2.6316
# 5 3.8416 0.4 4.2416

Этот фрагмент проверен запуском скриптом tools/test-generalization.py. Скрипт также сверяет формулу с моделированием: многократно зашумляет метки, считает прогнозы kNN и сравнивает выборочные смещение и дисперсию с аналитическими. Там же проверены числа о концентрации расстояний и ребре подкуба, формулы кривых обучения и double descent (моделированием) и числа, которые показывают рисунки.

Кривые в scikit-learn

Масштабирование стоит внутри Pipeline, чтобы на каждом фолде оно обучалось только на обучающей части; иначе статистики validation протекают в признаки.

import numpy as np
from sklearn.model_selection import StratifiedKFold, learning_curve, validation_curve
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

model = make_pipeline(StandardScaler(), KNeighborsClassifier())
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)

ks = [1, 3, 5, 9, 17, 33, 65]
train_scores, val_scores = validation_curve(
    model, X, y, param_name="kneighborsclassifier__n_neighbors",
    param_range=ks, cv=cv, scoring="accuracy")
train_err = 1 - train_scores.mean(axis=1)   # среднее по фолдам
val_err = 1 - val_scores.mean(axis=1)

Ключевые статьи

  • Cover, Hart. Nearest Neighbor Pattern Classification, 1967 — асимптотическая граница ошибки 1-NN через байесовскую.
  • Geman, Bienenstock, Doursat. Neural Networks and the Bias/Variance Dilemma, 1992 — разложение bias–variance и дилемма ёмкости для непараметрических оценок.
  • Beyer, Goldstein, Ramakrishnan, Shaft. When Is “Nearest Neighbor” Meaningful?, 1999 — условие концентрации расстояний в высокой размерности.
  • Domingos. A Unified Bias-Variance Decomposition and its Applications, 2000 — определения bias и variance для произвольной потери, включая 0–1.
  • Hastie, Tibshirani, Friedman. The Elements of Statistical Learning, 2-е изд., 2009 — гл. 2.5 (проклятие размерности), 7.2–7.3 (bias–variance и формула для kNN).
  • Belkin, Hsu, Ma, Mandal. Reconciling modern machine learning practice and the bias-variance trade-off, PNAS 2019 — double descent на нескольких семействах моделей.
  • Belkin, Hsu, Xu. Two models of double descent for weak features, SIAM J. Math. Data Sci. 2020 — точный риск наименьших квадратов с минимальной нормой и пик при \(p\approx n\).
  • Nakkiran, Kaplun, Bansal, Yang, Barak, Sutskever. Deep Double Descent: Where Bigger Models and More Data Hurt, 2019 / ICLR 2020 — double descent по размеру модели, числу эпох и объёму данных.
