Логистическая регрессия, наивный Байес, калибровка, n-граммные языковые модели и дистилляция опираются на одни и те же величины: правдоподобие, энтропию, cross-entropy и KL-дивергенцию, а вероятности классов получают через softmax. Здесь они собраны в один компактный справочник: определения, связи, из-за которых «минимизировать cross-entropy», «максимизировать правдоподобие» и «минимизировать KL» — одно и то же, и численно устойчивое вычисление. Через все величины проходит один пример — распределение отзывов по трём классам. Базовая теория вероятностей предполагается.

Правдоподобие, MLE и MAP

Пусть модель \(q_\theta\) задаёт вероятность наблюдения, а выборка \(x_1,\dots,x_n\) независима. Правдоподобие (likelihood) — вероятность выборки как функция параметров, оценка максимального правдоподобия (maximum likelihood estimation, MLE) — её максимум:

\[L(\theta)=\prod_{i=1}^{n}q_\theta(x_i),\qquad \hat\theta_{\text{MLE}}=\arg\max_\theta\sum_{i=1}^{n}\log q_\theta(x_i).\]

Логарифм не меняет точку максимума, но превращает произведение в сумму: и производные проще, и нет исчезновения в машинной точности — произведение тысячи вероятностей порядка \(0.1\) равно \(10^{-1000}\), что меньше любого числа с плавающей точкой. Для условной модели классификатора то же самое пишут для \(q_\theta(y_i\mid x_i)\).

Пример. Из \(20\) размеченных отзывов \(12\) негативных, \(6\) нейтральных и \(2\) позитивных. Для категориального распределения с вероятностями \(q_k\) логарифм правдоподобия равен \(\sum_k n_k\log q_k\); максимум при условии \(\sum_k q_k=1\) (множитель Лагранжа) — частоты:

\[\hat q_k=\frac{n_k}{n},\qquad \hat q=(0.6,\;0.3,\;0.1).\]

Отсюда и главный недостаток MLE на малых данных: класс или слово, ни разу не встретившиеся в выборке, получают вероятность ноль, и логарифм вероятности любого нового текста с ними равен \(-\infty\). Так ломаются наивный Байес и n-граммные языковые модели без сглаживания.

MAP (maximum a posteriori) добавляет априорное распределение параметров: \(\hat\theta_{\text{MAP}}=\arg\max_\theta\big[\sum_i\log q_\theta(x_i)+\log p(\theta)\big]\). Гауссовское априорное распределение весов даёт штраф L2, лапласовское — L1; это разобрано в разделе о регуляризации главы «Классический ML». Для категориального распределения с априорным Дирихле с параметром \(\alpha\) MAP-оценка равна \(\frac{n_k+\alpha-1}{n+K(\alpha-1)}\): сглаживание Лапласа «прибавить единицу к каждому счётчику» — это MAP при \(\alpha=2\) или апостериорное среднее при \(\alpha=1\). С ростом \(n\) вклад априорного распределения исчезает.

Энтропия и cross-entropy

Энтропия распределения \(p\) по \(K\) исходам — средняя «неожиданность» \(-\log p_k\):

\[H(p)=-\sum_{k}p_k\log p_k,\qquad 0\le H(p)\le\log K.\]

Ноль — у вырожденного распределения, \(\log K\) — у равномерного. С натуральным логарифмом единица измерения — наты, с двоичным — биты; по Шеннону, \(H(p)\) в битах — нижняя граница средней длины кода без потерь для исходов из \(p\). В примере \(H(\hat q)=0.898\) ната (\(1.30\) бита) при максимуме \(\log 3=1.099\).

Cross-entropy — средняя неожиданность исходов из \(p\), если оценивать их распределением модели \(q\):

\[H(p,q)=-\sum_{k}p_k\log q_k.\]

Если цель — один правильный класс \(y\) (one-hot), остаётся одно слагаемое: \(H(\text{one-hot}_y,q)=-\log q_y\). Среднее по выборке \(-\frac1n\sum_i\log q_\theta(y_i\mid x_i)\) — это и есть log-loss классификатора и отрицательный средний логарифм правдоподобия. Поэтому для классификации «минимизировать cross-entropy» и «искать MLE» — одна и та же задача. Экспонента от средней cross-entropy на токен — perplexity языковой модели.

Пусть модель для отзыва выдаёт логиты \(z=(0.5,\;1.0,\;0.0)\); после softmax (ниже) это \(q=(0.307,\;0.506,\;0.186)\). Если отзыв негативный, потеря на нём \(-\log0.307=1.180\). Относительно мягкой цели \(\hat q=(0.6,0.3,0.1)\) cross-entropy равна \(H(\hat q,q)=1.080\).

KL-дивергенция

Определение и связь с cross-entropy

\[\mathrm{KL}(p\,\|\,q)=\sum_k p_k\log\frac{p_k}{q_k}=H(p,q)-H(p)\;\ge\;0.\]

Неотрицательность — неравенство Гиббса: по неравенству Йенсена \(-\mathrm{KL}=\sum_k p_k\log\frac{q_k}{p_k}\le\log\sum_k q_k\le0\), равенство только при \(p=q\). В примере \(\mathrm{KL}(\hat q\,\|\,q)=1.080-0.898=0.182\).

Если \(p\) фиксировано — это данные, — \(H(p)\) от модели не зависит, и минимизация cross-entropy по \(q\) равносильна минимизации KL. Для эмпирического распределения \(\hat p\) выборки:

\[-\frac1n\log L(\theta)=H(\hat p,q_\theta)=H(\hat p)+\mathrm{KL}(\hat p\,\|\,q_\theta).\]

MLE выбирает модель, ближайшую к эмпирическому распределению в смысле KL. Тот же довод объясняет, почему при дистилляции минимизация KL к распределению учителя совпадает с cross-entropy по его мягким меткам (функции потерь).

KL — не расстояние

KL несимметрична и не удовлетворяет неравенству треугольника. Если \(q_k=0\) там, где \(p_k>0\), то \(\mathrm{KL}(p\,\|\,q)=\infty\) — ещё один довод в пользу сглаживания. От направления зависит и то, какую модель даёт минимизация:

  • \(\mathrm{KL}(p\,\|\,q)\) усредняет по \(p\) и сильно штрафует малое \(q\) там, где \(p\) велико: \(q\) старается накрыть всю массу \(p\) (mass-covering). Это направление минимизирует MLE.
  • \(\mathrm{KL}(q\,\|\,p)\) усредняет по \(q\) и штрафует большое \(q\) там, где \(p\) мало: \(q\) садится на одну моду (mode-seeking). Это направление минимизирует вариационный вывод.

Взаимная информация

Взаимная информация (mutual information) — KL между совместным распределением и произведением маргинальных:

\[I(X;Y)=\mathrm{KL}\big(p(x,y)\,\|\,p(x)\,p(y)\big)=H(Y)-H(Y\mid X)\;\ge\;0.\]

Она равна нулю только при независимости и показывает, на сколько знание \(X\) уменьшает неопределённость \(Y\). На ней основан отбор признаков-слов для классификатора и интерпретация контрастивных потерь вроде InfoNCE.

Softmax, log-sum-exp и градиент cross-entropy

Softmax и его избыточность

Классификатор выдаёт логиты \(z\in\mathbb R^K\) — произвольные числа; softmax превращает их в распределение:

\[q_k=\frac{e^{z_k}}{\sum_{j}e^{z_j}},\qquad \log q_k=z_k-\operatorname{LSE}(z),\qquad \operatorname{LSE}(z)=\log\sum_j e^{z_j}.\]

Прибавление одной константы ко всем логитам не меняет \(q\), поэтому у \(K\) логитов только \(K-1\) степеней свободы. При \(K=2\) и \(z=(t,0)\) softmax превращается в сигмоиду \(\sigma(t)=1/(1+e^{-t})\): бинарная логистическая регрессия — частный случай. Деление логитов на температуру \(T\) сохраняет порядок классов и меняет только резкость распределения — подробно в разделе о декодировании.

Устойчивое вычисление

Наивная формула ломается на больших логитах: \(e^{z}\) переполняет float64 уже при \(z\approx710\). Сдвиг на максимум \(m=\max_j z_j\) решает проблему без изменения результата:

\[\operatorname{LSE}(z)=m+\log\sum_j e^{z_j-m}.\]

Наибольшая экспонента равна единице, так что переполнения нет, а сумма не меньше единицы, так что логарифм конечен. Для \(z=(1000,999,998)\) получаем \(\operatorname{LSE}=1000.408\) и \(\log q=(-0.408,-1.408,-2.408)\), хотя \(e^{1000}\) не представимо. Логарифм вероятностей нужно считать как \(z-\operatorname{LSE}(z)\), а не как \(\log\) от уже вычисленного softmax: очень малая \(q_k\) округлится до нуля, и потеря станет бесконечной.

Градиент по логитам

Подставим \(\log q_k\) в cross-entropy с целью \(p\), \(\sum_k p_k=1\):

\[\mathcal L(z)=-\sum_k p_k z_k+\operatorname{LSE}(z),\qquad \frac{\partial\mathcal L}{\partial z_k}=q_k-p_k,\qquad \nabla^2_z\mathcal L=\operatorname{diag}(q)-qq^\top\succeq0.\]

Градиент — «прогноз минус цель»: ограничен по модулю единицей и не затухает, когда модель уверенно ошибается. В примере \(q-\hat q=(-0.293,\;0.206,\;0.086)\): шаг спуска поднимает логит негативного класса и опускает нейтральный. Гессиан положительно полуопределён, поэтому cross-entropy выпукла по логитам. Для двух классов это \(\sigma(t)-y\) и \(\sigma(t)\big(1-\sigma(t)\big)\) — из этих двух выражений получаются градиент логистической регрессии, шаг Ньютона в её обучении и значения листьев в градиентном бустинге для классификации.

Три тождества, которые стоит помнить: cross-entropy с one-hot целью — это \(-\log q_y\); \(H(p,q)=H(p)+\mathrm{KL}(p\,\|\,q)\), поэтому MLE минимизирует KL от данных до модели; градиент cross-entropy по логитам равен \(q-p\).

На практике

Все величины без библиотек

Код считает пример раздела в логарифмической шкале и проверяет устойчивость на больших логитах.

from math import exp, log

def logsumexp(z):
    m = max(z)
    return m + log(sum(exp(v - m) for v in z))

def log_softmax(z):
    lse = logsumexp(z)
    return [v - lse for v in z]

def entropy(p):
    return -sum(pk * log(pk) for pk in p if pk > 0)

def cross_entropy(p, z):          # p — целевое распределение, z — логиты
    return -sum(pk * lq for pk, lq in zip(p, log_softmax(z)) if pk > 0)

p, z = [0.6, 0.3, 0.1], [0.5, 1.0, 0.0]
q = [exp(v) for v in log_softmax(z)]
print([round(v, 3) for v in q])
print(round(entropy(p), 3), round(cross_entropy(p, z), 3),
      round(cross_entropy(p, z) - entropy(p), 3))
print([round(qk - pk, 3) for pk, qk in zip(p, q)])
print(round(logsumexp([1000, 999, 998]), 3))
# [0.307, 0.506, 0.186]
# 0.898 1.08 0.182
# [-0.293, 0.206, 0.086]
# 1000.408

PyTorch

import torch
import torch.nn.functional as F

logits = torch.tensor([[0.5, 1.0, 0.0]])
F.cross_entropy(logits, torch.tensor([0]))              # -log q_0: класс по индексу
soft = torch.tensor([[0.6, 0.3, 0.1]])
F.cross_entropy(logits, soft)                           # цель — распределение
F.kl_div(F.log_softmax(logits, dim=-1), soft,
         reduction="batchmean")                         # KL(soft || q)
F.binary_cross_entropy_with_logits(torch.tensor([2.0]), torch.tensor([1.0]))

Сверено с документацией PyTorch 2.14, не запускалось. Тихие ошибки:

  • cross_entropy и CrossEntropyLoss ждут логиты, а не вероятности: softmax перед ними применится дважды. Обучение пойдёт, но с искажённым градиентом.
  • kl_div(input, target) ждёт input в логарифмах и считает \(\mathrm{KL}(\text{target}\,\|\,\cdot)\) — порядок аргументов обратный записи формулы. Редукция "mean" по умолчанию делит ещё и на число классов; значение KL на пример даёт "batchmean".
  • Сигмоида с отдельным BCELoss менее устойчива, чем BCEWithLogitsLoss, которая внутри использует log-sum-exp.
  • Параметр label_smoothing заменяет one-hot цель смесью с равномерным распределением; это меняет и минимум потери: модель больше не стремится к вероятности \(1\).
